음운 탈락

원래 있던 소리 하나가 실제 발음이나 형태 결합 과정에서 사라져 음운의 수가 줄어드는 현상입니다. 무엇이 없어졌는지를 먼저 찾으면 교체·첨가·축약과 쉽게 구별할 수 있습니다.

핵심은 A → ∅입니다. 변화 전에는 있던 음운이 변화 뒤에는 실현되지 않아 음운 수가 줄어듭니다. 다만 같은 표면 발음도 이론이나 교과서에 따라 분석 단계가 달라질 수 있으므로, 규범이 명확히 설명하는 사례와 해석이 갈릴 수 있는 사례를 나누어 보아야 합니다.

1. 탈락은 ‘있던 음운이 없어지는가’를 보는 변화 방향이다

A → ∅

음운 탈락은 원래 있던 음운이 특정 환경에서 발음되지 않거나 형태 결합 과정에서 사라지는 현상입니다. 교체처럼 다른 음운으로 바뀌는 것이 아니라, 음운 하나가 없어져 전체 음운 수가 줄어든다는 점이 핵심입니다.

값 → [갑]

겹받침 ㅄ 가운데 ㅅ이 발음되지 않습니다. 자음군 단순화의 대표적인 탈락 사례입니다.

낳아 → [나아]

ㅎ이 모음으로 시작하는 형식 형태소 앞에서 발음되지 않습니다.

크 + 어서 → 커서

어간 끝 모음 ㅡ가 특정 환경에서 탈락합니다.

가 + 아서 → 가서

같은 모음이 연속될 때 하나가 탈락하는 동일 모음 탈락으로 볼 수 있습니다.

2. 탈락은 세 가지 질문으로 판별한다

질문판단
변화 전에 실제로 어떤 음운이 있었는가?형태소의 기본형이나 결합 전 형태를 확인합니다.
변화 뒤 그 음운이 다른 소리로 바뀌었는가, 아니면 없어졌는가?다른 음운이 나타나면 교체, 아무 소리도 남지 않으면 탈락을 의심합니다.
음운의 수가 줄었는가?탈락은 보통 변화 뒤 음운 수가 하나 이상 줄어듭니다.
예: 숲 → [숩]은 ㅍ이 ㅂ으로 바뀌므로 교체이고, 값 → [갑]은 ㅅ이 사라지므로 탈락입니다.

3. 자음군 단순화는 겹받침의 한 자음이 사라지는 탈락이다

표준 발음법 제10·11항은 겹받침이 어말이나 자음 앞에서 하나의 자음으로 발음되는 경우를 규정합니다. 학교 문법에서는 이때 겹받침을 이루던 두 자음 중 하나가 없어지므로 자음군 단순화를 탈락으로 보는 것이 일반적입니다.

값 → [갑]

ㅄ 가운데 ㅅ이 탈락합니다.

닭도 → [닥또]

ㄺ 가운데 ㄹ이 발음되지 않고, 뒤에서는 된소리되기가 이어집니다.

삶 → [삼]

ㄻ 가운데 ㄹ이 탈락하여 [ㅁ]만 남습니다.

읊다 → [읍따]

ㄿ에서 ㄹ이 탈락하고 남은 ㅍ은 음절 끝에서 [ㅂ]으로 실현됩니다.

주의: 겹받침 뒤에 모음으로 시작하는 조사·어미·접미사가 오면 항상 자음군 단순화가 일어나는 것은 아닙니다. 예를 들어 닭을은 [달글]처럼 뒤 자음이 연음되어 두 자음이 모두 실현됩니다.

4. ㅎ 탈락은 모음으로 시작하는 형식 형태소 앞에서 ㅎ이 사라지는 경우가 대표적이다

표준 발음법 제12항 해설은 ㅎ(ㄶ, ㅀ) 뒤에 모음으로 시작하는 어미나 접미사가 결합할 때 ㅎ이 다른 소리로 바뀌는 것이 아니라 탈락한다고 설명합니다.

낳은 → [나은]

ㅎ이 탈락합니다.

많아 → [마나]

ㄶ 가운데 ㅎ이 발음되지 않습니다.

싫어도 → [시러도]

ㅀ 가운데 ㅎ이 탈락하고 ㄹ이 이어집니다.

쌓이다 → [싸이다]

ㅎ이 모음으로 시작하는 접미사 앞에서 탈락합니다.

그러나 ㄶ·ㅀ 뒤에 자음이 오는 모든 경우를 하나의 이름으로 단정하기는 어렵습니다. 국립국어원도 자음 앞에서 ㅎ이 발음되지 않는 일부 사례는 자음군 단순화로 볼지 ㅎ 탈락으로 볼지 견해가 갈릴 수 있다고 안내합니다.

5. 모음 탈락은 활용 과정에서도 나타난다

탈락은 자음에서만 일어나지 않습니다. 용언 활용이나 조사·어미 결합에서 모음 하나가 없어지는 경우도 있습니다.

유형예핵심
어간 말 ㅡ 탈락크 + 어서 → 커서, 쓰 + 어 → 써어간 끝 ㅡ가 아/어 계열 어미 앞에서 탈락합니다.
동일 모음 탈락가 + 아서 → 가서, 사 + 아야 → 사야같은 모음이 연속될 때 하나가 탈락합니다.
어미·조사의 으 탈락알 + 으면 → 알면, 길 + 으로 → 길로유음이나 모음 뒤에서 으가 나타나지 않는 현상을 탈락으로 설명하기도 합니다.
분석 기준: 모음 탈락의 세부 유형과 형태소 분석은 문법 체계에 따라 설명 방식이 다를 수 있습니다. 시험이나 수업에서는 사용하는 교과서의 형태소 분석 기준을 우선하는 것이 안전합니다.

6. 교체·축약과는 ‘무엇이 남는가’가 다르다

변동변화 방향대표 예
교체A → B국물 [궁물] : ㄱ → ㅇ
탈락A → ∅값 [갑] : ㅅ이 사라짐
첨가∅ → A없던 음운이 새로 생김
축약A + B → C좋고 [조코] : ㅎ과 ㄱ이 합쳐져 ㅋ으로 실현

특히 탈락과 축약을 헷갈리지 않아야 합니다. 탈락은 음운 하나가 아무 대체음 없이 사라지는 변화이고, 축약은 두 음운의 성질이 하나의 새 음운에 합쳐지는 변화입니다.

7. 복합 사례에서는 ‘현상 이름’보다 규범의 실제 발음을 먼저 확인한다

한 단어 안에서 탈락과 교체가 함께 일어나는 경우가 많습니다. 예를 들어 읊다 [읍따]는 겹받침에서 한 자음이 사라지는 탈락과 남은 자음의 종성 실현, 뒤 자음의 된소리되기가 함께 관련될 수 있습니다.

또 않는, 닳는처럼 ㄶ·ㅀ 뒤에 자음이 오는 사례는 ㅎ을 발음하지 않는다는 규범은 분명하지만, 그것을 자음군 단순화로 부를지 ㅎ 탈락으로 부를지는 설명 방식이 갈릴 수 있습니다. 이런 경우에는 변동 횟수나 적용 순서를 하나의 절대 공식으로 만들기보다 표준 발음과 해당 교과서의 분석 기준을 함께 확인해야 합니다.

판별 원칙: 명확한 사례에서는 ‘어떤 음운이 실제로 사라졌는가’를 찾고, 경계 사례에서는 규범이 정한 발음과 교과서의 분석 용어를 분리해서 봅니다.
