비음화

받침의 ㄱ·ㄷ·ㅂ 계열 소리가 뒤의 비음 ㄴ·ㅁ을 만나면 각각 ㅇ·ㄴ·ㅁ으로 바뀝니다. 무엇이 바뀌고 무엇은 그대로인지 보면 규칙이 선명해집니다.

핵심 공식은 ㄱ → ㅇ, ㄷ → ㄴ, ㅂ → ㅁ / __ ㄴ·ㅁ입니다. 뒤의 ㄴ·ㅁ은 그대로 있고, 앞의 받침이 같은 조음 위치의 비음으로 바뀝니다.
목차

  2. 세 가지 변화
  3. 왜 ㅇ·ㄴ·ㅁ으로 바뀌는가
  4. 표기에 다른 받침이 있어도 적용되는 이유
  5. 단어 사이에서도 일어나는가
  6. ㄹ의 비음화는 같은 규칙인가

1. 비음화는 뒤의 비음 때문에 앞 받침이 비음으로 바뀌는 교체다

표준 발음법 제18항은 받침의 ㄱ·ㄷ·ㅂ 계열이 뒤의 ㄴ, ㅁ 앞에서 각각 ㅇ, ㄴ, ㅁ으로 발음된다고 규정합니다. 학교 문법의 변화 방향으로 보면 한 음운이 다른 음운으로 바뀌므로 교체에 해당합니다.

국물 → [궁물]

ㄱ이 ㅁ 앞에서 ㅇ으로 바뀝니다.

닫는 → [단는]

ㄷ이 ㄴ 앞에서 ㄴ으로 바뀝니다.

밥물 → [밤물]

ㅂ이 ㅁ 앞에서 ㅁ으로 바뀝니다.

국민 → [궁민]

한자어에서도 같은 조건이면 ㄱ이 ㅇ으로 바뀝니다.

확인할 것: 뒤에 비음 ㄴ·ㅁ이 오는지, 앞 받침이 ㄱ·ㄷ·ㅂ 계열인지 먼저 봅니다.

2. 비음화의 변화는 세 줄로 정리할 수 있다

변화뒤 환경대표 예결과
ㄱ 계열 → ㅇㄴ 또는 ㅁ 앞먹는, 국물[멍는], [궁물]
ㄷ 계열 → ㄴㄴ 또는 ㅁ 앞닫는, 맞는[단는], [만는]
ㅂ 계열 → ㅁㄴ 또는 ㅁ 앞잡는, 밥물[잠는], [밤물]

표준 발음법은 실제 표기에 ㄲ·ㅋ·ㄳ·ㄺ, ㅅ·ㅆ·ㅈ·ㅊ·ㅌ·ㅎ, ㅍ·ㄼ·ㄿ·ㅄ 등이 쓰인 경우도 각각 ㄱ·ㄷ·ㅂ 계열로 묶어 규정합니다.

3. 조음 위치는 유지하고 조음 방식이 비음으로 바뀐다

비음화의 세 결과가 ㅇ·ㄴ·ㅁ인 것은 임의적이지 않습니다. 표준 발음법 해설은 앞선 ㄱ·ㄷ·ㅂ이 뒤 비음의 조음 방식에 동화되면서, 원래와 같은 조음 위치의 비음으로 바뀐다고 설명합니다.

원래 소리비음화 결과공통점
ㄱㅇ혀의 뒤쪽을 이용하는 자리
ㄷㄴ혀끝·잇몸 부근의 자리
ㅂㅁ두 입술을 이용하는 자리

그래서 비음화는 ‘아무 자음이나 코소리로 바뀐다’가 아니라, 정해진 받침 계열이 ㄴ·ㅁ 앞에서 대응하는 비음으로 바뀌는 현상으로 이해해야 합니다.

4. 표기에 ㅅ·ㅈ·ㅊ·ㅎ 등이 보여도 제18항의 대상이 될 수 있다

비음화 문제에서 자주 헷갈리는 부분은 표기상 받침이 ㄱ·ㄷ·ㅂ이 아닌 경우입니다. 제18항은 ㄷ 계열에 ㅅ·ㅆ·ㅈ·ㅊ·ㅌ·ㅎ을, ㅂ 계열에 ㅍ·ㄼ·ㄿ·ㅄ 등을 함께 제시합니다.

맞는 → [만는]

표기는 ㅈ 받침이지만 규정에서는 ㄷ 계열에 포함되어 ㄴ 앞에서 [ㄴ]으로 실현됩니다.

꽃망울 → [꼰망울]

ㅊ 받침도 ㄷ 계열로 다루어 ㅁ 앞에서 [ㄴ]으로 발음됩니다.

앞마당 → [암마당]

ㅍ 받침은 ㅂ 계열로 묶여 ㅁ 앞에서 [ㅁ]으로 바뀝니다.

없는 → [엄는]

ㅄ이 포함된 경우도 규정에 따라 비음화 결과가 나타납니다.

분석 주의: 이런 예를 설명할 때 ‘항상 끝소리 규칙을 먼저 적용한 뒤 비음화한다’는 하나의 순서를 모든 사례에 기계적으로 강제하지 않는 편이 안전합니다. 표준 발음 규정이 제시하는 실제 조건과 결과를 먼저 확인하고, 세부 분석 단계는 사용하는 교과서의 기준을 따릅니다.

5. 비음화는 한 단어 안에서만 일어나는 현상이 아니다

표준 발음법 제18항의 붙임은 두 단어를 이어 한 마디로 발음할 때에도 같은 현상이 적용된다고 규정합니다.

책 넣는다 → [챙넌는다]

앞 단어의 받침 ㄱ이 뒤 단어 첫소리 ㄴ의 영향으로 ㅇ이 됩니다.

밥 먹는다 → [밤멍는다]

‘밥’의 ㅂ이 ㅁ 앞에서 ㅁ으로 바뀌고, 뒤에서도 비음화가 이어집니다.

값 매기다 → [감매기다]

단어 경계를 사이에 두고도 조건이 맞으면 비음화가 나타납니다.

흙 말리다 → [흥말리다]

겹받침이 포함된 경우에도 규정된 발음 결과를 확인해야 합니다.

따라서 띄어쓰기가 되어 있다고 해서 음운 현상이 반드시 끊기는 것은 아닙니다. 실제로 한 마디처럼 이어 발음하는지를 함께 봐야 합니다.

6. ‘ㄹ의 비음화’는 제18항의 공식과 구별해야 한다

비음화라는 이름 아래에는 ㄹ이 ㄴ으로 바뀌는 현상도 함께 언급됩니다. 표준 발음법 제19항은 받침 ㅁ·ㅇ 뒤의 ㄹ을 [ㄴ]으로 발음하고, 붙임에서는 받침 ㄱ·ㅂ 뒤의 ㄹ도 [ㄴ]으로 발음한다고 규정합니다.

담력 → [담녁]

ㅁ 뒤의 ㄹ이 ㄴ으로 바뀝니다.

강릉 → [강능]

ㅇ 뒤의 ㄹ이 ㄴ으로 바뀝니다.

막론 → [망논]

ㄹ이 먼저 ㄴ으로 바뀐 뒤, 앞의 ㄱ이 새로 생긴 ㄴ의 영향으로 ㅇ이 되는 과정이 관여합니다.

협력 → [혐녁]

ㄹ의 비음화와 앞 자음의 비음화가 함께 나타나는 사례입니다.

구별: 제18항의 기본 비음화는 ㄱ·ㄷ·ㅂ 계열 받침이 ㄴ·ㅁ 앞에서 바뀌는 현상이고, 제19항의 ㄹ 비음화는 ㄹ 자체가 ㄴ으로 바뀌는 별도 환경입니다.

7. ㄴ과 ㄹ이 만났다고 항상 비음화되는 것은 아니다

비음이 아닌 자음이 비음을 만나면 무조건 비음화된다고 외우면 틀립니다. 특히 ㄴ과 ㄹ이 인접하면 유음화가 적용되어 ㄴ이 ㄹ로 바뀌는 경우가 있습니다.

신라 → [실라]

ㄴ이 ㄹ과 만나 ㄹ로 바뀌는 유음화입니다.

난로 → [날로]

이 역시 ㄴ이 ㄹ로 바뀌는 유음화입니다.

따라서 문제에서는 단순히 ‘비음이 보이는가’를 찾지 말고, 어떤 자음이 어느 자음의 영향을 받아 무엇으로 바뀌었는지를 확인해야 합니다.

8. 비음화를 판별하는 가장 안정적인 순서

순서확인할 것
1뒤 음절 첫소리가 ㄴ 또는 ㅁ인지 확인한다.
2앞 받침이 ㄱ·ㄷ·ㅂ 계열에 속하는지 확인한다.
3ㄱ→ㅇ, ㄷ→ㄴ, ㅂ→ㅁ의 대응을 적용해 실제 발음을 확인한다.
4ㄹ이 포함된 경우에는 제19항의 ㄹ 비음화나 제20항의 유음화와 구별한다.
5여러 변동이 겹치는 낱말은 최종 발음만 보지 말고 변화 조건을 나누어 본다.
