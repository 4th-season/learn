음운 축약

서로 이웃한 두 소리가 결합하면서 하나의 새로운 소리나 한 음절로 줄어드는 현상입니다. 자음에서는 ㅎ과 예사소리가 거센소리 하나로 합쳐지는 경우가 대표적이고, 모음에서는 두 음절이 한 음절로 줄어드는 활용형이 자주 다뤄집니다.

핵심은 A + B → C입니다. 한 소리가 없어지는 탈락과 달리, 두 소리의 성질이 결합된 새로운 결과가 나타나는 것이 축약의 대표적인 모습입니다.
목차
  1. 음운 축약이란 무엇인가
  2. 거센소리되기
  3. ㅎ이 앞에 올 때
  4. ㅎ이 뒤에 올 때

  7. 축약과 교체의 경계
  8. 판별 순서

1. 축약은 둘이 만나 하나로 줄어드는 변화다

A + B → C

사전에서는 축약을 두 형태소가 만날 때 앞뒤의 두 음소나 음절이 하나의 음소나 음절이 되는 현상으로 설명합니다. 학교 문법에서는 보통 자음 축약과 모음 축약으로 나누어 학습합니다.

좋고 → [조코]

ㅎ과 ㄱ이 합쳐져 ㅋ 하나로 발음됩니다.

국화 → [구콰]

ㄱ과 ㅎ이 만나 ㅋ으로 줄어듭니다.

보아 → 봐

두 음절이 한 음절로 줄어드는 활용형입니다. 다만 음운론적 분석은 견해에 따라 달라질 수 있습니다.

되어 → 돼

표기와 음절 수는 줄지만, 반모음화로 분석하는 관점도 있습니다.

2. 자음 축약의 대표는 거센소리되기다

표준 발음법 제12항에서는 ㅎ이 ㄱ·ㄷ·ㅂ·ㅈ 계열과 만나 각각 ㅋ·ㅌ·ㅍ·ㅊ으로 발음되는 경우를 규정합니다. 두 자음이 따로 남는 것이 아니라 거센소리 하나로 실현되므로 학교 문법에서 대표적인 자음 축약으로 다룹니다.

결합결과대표 예
ㅎ + ㄱ / ㄱ + ㅎㅋ좋고[조코], 국화[구콰]
ㅎ + ㄷ / ㄷ + ㅎㅌ좋던[조턴], 맏형[마텽]
ㅎ + ㅂ / ㅂ + ㅎㅍ좁히다[조피다]
ㅎ + ㅈ / ㅈ + ㅎㅊ좋지[조치], 꽂히다[꼬치다]

3. 받침 ㅎ이 뒤 예사소리와 만나면 거센소리 하나가 된다

놓고 → [노코]

ㅎ + ㄱ → ㅋ

좋던 → [조턴]

ㅎ + ㄷ → ㅌ

쌓지 → [싸치]

ㅎ + ㅈ → ㅊ

많고 → [만코]

ㄶ의 ㅎ이 뒤 ㄱ과 결합해 ㅋ으로 실현됩니다.

ㄶ·ㅀ처럼 겹받침에 ㅎ이 들어 있는 경우에도 환경에 따라 남은 자음과 ㅎ의 결합을 함께 분석해야 합니다. 어떤 변동을 먼저 적용했다고 셀지는 교과서나 이론에 따라 다를 수 있습니다.

4. 예사소리 뒤에 ㅎ이 오는 경우에도 축약이 일어난다

거센소리되기는 ㅎ이 앞에 있을 때만 일어나는 현상이 아닙니다. ㄱ·ㄷ·ㅂ·ㅈ 계열 자음 뒤에 ㅎ이 와도 두 소리가 결합해 거센소리 하나로 실현될 수 있습니다.

먹히다 → [머키다]

ㄱ + ㅎ → ㅋ

밝히다 → [발키다]

받침 발음과 ㅎ의 결합이 이어져 ㅋ으로 실현됩니다.

좁히다 → [조피다]

ㅂ + ㅎ → ㅍ

앉히다 → [안치다]

받침 처리 뒤 ㅈ과 ㅎ이 결합하여 ㅊ으로 실현됩니다.

주의: 복합 사례에서는 자음군 단순화·음절 끝소리 규칙 등이 함께 관여할 수 있습니다. 최종 발음은 규범으로 확인하되, 변동의 세부 순서나 횟수는 사용하는 교과서 기준을 따르는 것이 안전합니다.

5. 모음 축약은 ‘두 음절이 한 음절로 줄어드는가’에 초점을 둔다

전통적인 학교 문법에서는 보아→봐, 되어→돼, 가리어→가려처럼 모음이 이어지는 활용형에서 두 음절이 한 음절로 줄어드는 현상을 모음 축약으로 설명해 왔습니다. 한글 맞춤법도 이런 줄어든 형태를 규정하고 있습니다.

결합줄어든 형태설명
보 + 아봐ㅗ와 ㅏ가 이어져 한 음절로 줄어든 형태
되 + 어돼ㅚ와 ㅓ가 이어져 한 음절로 줄어든 형태
가리 + 어가려ㅣ 뒤의 -어가 결합해 한 음절로 줄어든 형태
현대 음운론의 경계: 반모음을 하나의 음운으로 인정하는 관점에서는 보아→봐를 ㅗ가 반모음 w로 바뀌는 반모음화·교체로 분석할 수 있습니다. 따라서 모음 축약의 정확한 분류는 문법서마다 달라질 수 있습니다.

6. 축약과 탈락은 모두 수가 줄지만 결과가 다르다

구분변화 방향예핵심
축약A + B → C좋고→[조코]두 소리가 결합해 새로운 한 소리가 됨
탈락A → ∅값→[갑]있던 소리 하나가 사라짐
교체A → B국물→[궁물]한 소리가 다른 소리로 바뀜

따라서 단순히 ‘음운 수가 줄었다’만으로 축약을 판정하면 안 됩니다. 두 소리가 결합해 하나의 결과를 만들었는지를 먼저 확인해야 합니다.

7. 모음 축약과 반모음화는 문법 체계에 따라 경계가 달라진다

국립국어원도 최근 답변에서 `보아→봐`를 하나의 방식으로만 고정하기 어렵다고 설명합니다. 반모음을 하나의 음운으로 인정하면 ㅗ가 w로 바뀌는 교체로 볼 수 있고, 두 음절이 한 음절로 줄었다는 점에 초점을 두면 모음 축약으로 기술할 수 있습니다.

학습 기준: 자음 축약인 거센소리되기는 비교적 분명하게 두 자음이 하나로 합쳐지는 사례입니다. 반면 모음 축약은 반모음에 대한 관점에 따라 분석이 달라질 수 있으므로 시험에서는 교과서와 수업 기준을 우선합니다.

8. 축약 판별은 ‘둘이 하나가 되었는가’부터 확인한다

  1. 변화 전 소리 두 개를 찾습니다.
  2. 변화 뒤 둘이 결합한 하나의 결과가 남았는지 봅니다.
  3. 한 소리만 없어졌다면 탈락인지 확인합니다.
  4. 한 소리가 다른 소리로 바뀌었다면 교체인지 확인합니다.
  5. 모음이 줄어든 사례는 반모음화 분석 가능성을 확인하고 교과서 기준을 적용합니다.
