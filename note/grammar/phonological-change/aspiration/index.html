거센소리되기

ㅎ과 다른 자음이 만나 ㅋ·ㅌ·ㅍ·ㅊ 하나로 발음되는 현상입니다. 두 소리가 하나의 거센소리로 줄어들기 때문에 학교 문법에서는 대표적인 자음 축약으로 다룹니다.

핵심은 두 자음 → 거센소리 하나입니다. 다만 ㅎ이 있다고 언제나 거센소리가 되는 것은 아닙니다. ㅎ 뒤에 오는 자음의 종류, ㅎ 앞의 받침, 뒤 형태소의 성격에 따라 ㅎ 탈락·비음화·된소리되기 등 다른 결과가 나타날 수 있습니다.
목차
  1. 거센소리되기란 무엇인가
  2. ㅎ 뒤에서 일어나는 경우
  3. ㅎ 앞에서 일어나는 경우
  4. 다른 받침도 ㅎ과 만날 수 있다
  5. 왜 축약이라고 하는가
  6. ㅎ이 있다고 모두 거센소리되기는 아니다
  7. 잊히다는 어떻게 분석하는가
  8. 판별 순서

1. 거센소리되기는 두 자음이 하나의 거센소리로 줄어드는 현상이다

ㅎ + ㄱ·ㄷ·ㅈ → ㅋ·ㅌ·ㅊ
ㄱ·ㄷ·ㅂ·ㅈ + ㅎ → ㅋ·ㅌ·ㅍ·ㅊ

표준 발음법 제12항은 받침 ㅎ과 그 주변 자음이 결합할 때 두 소리를 따로 발음하지 않고 하나의 거센소리로 합쳐 발음하는 경우를 규정합니다. 이 현상을 보통 거센소리되기 또는 유기음화라고 부릅니다.

놓고 → [노코]

ㅎ과 뒤의 ㄱ이 합쳐져 ㅋ이 됩니다.

좋던 → [조턴]

ㅎ과 뒤의 ㄷ이 합쳐져 ㅌ이 됩니다.

먹히다 → [머키다]

받침 ㄱ과 뒤의 ㅎ이 합쳐져 ㅋ이 됩니다.

좁히다 → [조피다]

받침 ㅂ과 뒤의 ㅎ이 합쳐져 ㅍ이 됩니다.

2. 받침 ㅎ 뒤에서는 ㄱ·ㄷ·ㅈ이 ㅋ·ㅌ·ㅊ으로 바뀐다

받침 ㅎ이나 겹받침 ㄶ·ㅀ 뒤에 ㄱ·ㄷ·ㅈ이 오면 뒤 자음과 ㅎ이 합쳐져 거센소리로 발음됩니다. 이 방향의 규정에서는 ㅂ을 따로 넣지 않는다는 점도 기억해야 합니다.

결합결과예
ㅎ + ㄱㅋ놓고 [노코], 많고 [만코]
ㅎ + ㄷㅌ좋던 [조턴], 않던 [안턴]
ㅎ + ㅈㅊ쌓지 [싸치], 닳지 [달치]
주의: 흔히 ‘ㅎ과 예사소리가 만나면 모두 거센소리가 된다’고 외우지만, 표준 발음법의 이 방향은 실제로 ㄱ·ㄷ·ㅈ을 규정합니다. 환경을 정확히 확인해야 합니다.

3. 반대로 받침 ㄱ·ㄷ·ㅂ·ㅈ 뒤에 ㅎ이 와도 거센소리가 된다

표준 발음법 제12항 붙임 1은 반대 방향도 규정합니다. 받침 ㄱ·ㄷ·ㅂ·ㅈ이 뒤 음절의 ㅎ과 결합하면 각각 ㅋ·ㅌ·ㅍ·ㅊ으로 발음합니다.

각하 → [가카]

ㄱ + ㅎ → ㅋ

맏형 → [마텽]

ㄷ + ㅎ → ㅌ

넓히다 → [널피다]

ㅂ + ㅎ → ㅍ

꽂히다 → [꼬치다]

ㅈ + ㅎ → ㅊ

겹받침이 있는 밝히다[발키다], 넓히다[널피다], 앉히다[안치다]도 같은 규정과 연결됩니다. 다만 겹받침이나 대표음화가 함께 걸리는 말의 세부 분석 단계는 문법 체계에 따라 설명이 달라질 수 있습니다.

4. 표기에 ㅅ·ㅈ·ㅊ·ㅌ이 보여도 ㅎ 앞에서는 [ㅌ]으로 합쳐질 수 있다

표준 발음법 제12항 붙임 2는 규정에 따라 받침에서 [ㄷ]으로 발음되는 ㅅ·ㅈ·ㅊ·ㅌ도 뒤의 ㅎ과 결합하면 이에 준한다고 설명합니다.

옷 한 벌 → [오탄벌]

받침 ㅅ이 종성에서 [ㄷ] 계열로 실현되고 ㅎ과 결합해 [ㅌ]이 됩니다.

낮 한때 → [나탄때]

받침 ㅈ과 ㅎ의 결합 결과가 [ㅌ]으로 나타납니다.

꽃 한 송이 → [꼬탄송이]

받침 ㅊ과 뒤 ㅎ의 결합을 같은 원리로 설명합니다.

숱하다 → [수타다]

받침 ㅌ과 ㅎ이 만나 [ㅌ]으로 발음됩니다.

5. 거센소리되기는 왜 교체가 아니라 축약인가

거센소리되기의 핵심은 하나의 음운이 다른 음운으로 단순히 바뀌는 것이 아니라 두 자음이 하나의 새로운 자음으로 합쳐진다는 데 있습니다.

변동방향예
교체A → B국물[궁물] : ㄱ → ㅇ
탈락A → ∅값[갑] : ㅅ이 사라짐
축약A + B → C먹히다[머키다] : ㄱ + ㅎ → ㅋ

그래서 학교 문법에서는 거센소리되기를 자음 축약의 대표적인 사례로 다룹니다.

6. ㅎ이 보인다고 모두 거센소리되기는 아니다

놓아 → [노아]

뒤에 모음으로 시작하는 어미가 오므로 ㅎ이 탈락합니다. 거센소리되기가 아닙니다.

놓는 → [논는]

ㅎ 뒤에 ㄴ이 오면 [ㄴ]으로 발음됩니다. 거센소리되기와 다른 규정입니다.

닿소 → [다쏘]

ㅎ 뒤에 ㅅ이 오면 ㅅ을 [ㅆ]으로 발음합니다.

좋아하다 → [조아하다]

모든 초성 ㅎ이 탈락하거나 앞소리와 합쳐지는 것은 아닙니다.

거센소리되기를 판별할 때는 ‘ㅎ이 있는가’보다 ㅎ의 위치와 이웃한 자음이 무엇인가를 먼저 확인해야 합니다.

7. 잊히다는 [읻히다→이티다→이치다]로 반드시 나눌 필요가 없다

잊히다[이치다]는 학습 과정에서 자주 혼동되는 말입니다. 표준 발음법 제12항의 붙임 1에서는 받침 ㅈ과 뒤의 ㅎ이 합쳐져 ㅊ으로 발음되는 구조를 제시합니다. 따라서 학교 문법에서는 잊- + -히-에서 ㅈ과 ㅎ이 곧바로 ㅊ으로 축약된 것으로 설명할 수 있습니다.

용언 어간 뒤에 접미사 -히-가 결합하는 먹히다·꽂히다·잊히다 같은 사례는 평음 계열 자음과 ㅎ이 곧바로 축약된다고 설명하는 것이 표준 발음법 해설과 잘 맞습니다.

반면 다른 환경에서는 먼저 받침이 대표음으로 바뀌거나 겹받침이 단순화된 뒤 ㅎ과 축약되는 것으로 설명할 수 있습니다. 여러 변동이 겹치는 말의 세부 순서와 횟수는 교과서의 분석 기준을 우선하는 것이 안전합니다.

8. 판별할 때는 ㅎ의 앞뒤부터 본다

확인 순서판별
1. ㅎ 뒤에 ㄱ·ㄷ·ㅈ이 오는가?그렇다면 ㅋ·ㅌ·ㅊ으로 합쳐지는지 확인합니다.
2. ㄱ·ㄷ·ㅂ·ㅈ 계열 받침 뒤에 ㅎ이 오는가?ㅋ·ㅌ·ㅍ·ㅊ으로 합쳐지는지 확인합니다.
3. ㅎ 뒤가 모음·ㄴ·ㅅ인가?ㅎ 탈락, [ㄴ] 실현, 된소리되기 등 다른 제12항 규정을 확인합니다.
4. 겹받침이나 대표음화가 함께 있는가?최종 표준 발음을 먼저 확정하고 세부 변동 순서는 교과서 기준을 따릅니다.

함께 읽기

음운 축약 — 두 소리가 하나로 줄어드는 현상ㅎ 탈락 — 모음 앞에서 ㅎ이 사라지는 조건구개음화 — ㄷ·ㅌ이 ㅈ·ㅊ으로 바뀌는 조건음운 변동과 발음 전체 지도
