파생어와 합성어 차이

둘 다 복합어이지만 무엇이 결합해 마지막 단어가 되었는지를 보면 갈라집니다. 핵심은 형태소를 모두 늘어놓는 것이 아니라 가장 마지막 직접 구성 성분에 접사가 포함되어 있는지 확인하는 것입니다.

파생어는 실질 형태소나 어근에 접사가 결합해 만들어진 단어이고, 합성어는 접사 없이 둘 이상의 실질 형태소가 결합해 만들어진 단어입니다. 복잡한 단어에서는 직접 구성 성분을 먼저 찾는 것이 가장 안전합니다.

1. 파생어와 합성어는 ‘마지막 결합에 접사가 있는가’에서 갈린다

파생어와 합성어는 모두 복합어입니다. 차이는 단어 안에 형태소가 몇 개인지가 아니라, 현재 단어를 직접 만든 결합이 무엇이었는지에 있습니다.

파생어

실질 형태소에 접사가 결합해 만들어집니다. 예: 지우- + -개 → 지우개.

합성어

접사 없이 둘 이상의 실질 형태소가 결합해 만들어집니다. 예: 꽃 + 집 → 꽃집.

가장 중요한 질문: “이 단어의 직접 구성 성분 가운데 접사가 있는가?” 접사가 있다면 파생어, 없다면 두 성분이 실질 형태소인지 확인해 합성어를 판단합니다.

2. 왜 형태소 전체보다 ‘직접 구성 성분’을 먼저 보아야 하는가

긴 단어는 여러 형태소와 여러 형성 단계를 포함할 수 있습니다. 이때 모든 형태소를 한꺼번에 늘어놓으면 어느 결합이 현재 단어를 직접 만들었는지가 보이지 않습니다.

직접 구성 성분은 둘 이상의 형태소가 결합한 구조를 가장 마지막 결합 단계의 두 요소로 나누어 보는 방식입니다. 따라서 최종 단어가 파생어인지 합성어인지 판단할 때 특히 중요합니다.

지우개 → 지우- + -개

직접 구성 성분: 지우- / -개

-개: 접미사

최종 판정: 직접 구성 성분에 접사가 있으므로 파생어

꽃집 → 꽃 + 집

직접 구성 성분: 꽃 / 집

꽃, 집: 각각 실질 의미를 가진 명사

최종 판정: 접사 없이 실질 형태소끼리 결합했으므로 합성어

3. 파생어 — 접사가 단어 형성에 참여한다

파생어는 실질 형태소에 접두사나 접미사가 붙어 새로운 단어가 된 말입니다. 접사는 혼자 하나의 단어로 쓰이지 않고 특정 어근이나 단어에 붙어 의미를 더하거나 단어의 문법적 성격을 바꾸는 역할을 합니다.

단어직접 구성 성분판별 근거
지우개지우- + -개-개가 접미사이므로 파생어
백분율백분 + -율-율이 접미사이므로 파생어
제일제- + 일제-가 접두사로 결합한 것으로 볼 수 있어 파생어
주의: 접사는 뜻이 약하거나 문법적 기능만 있는 요소라고 단정할 수 없습니다. 어떤 접사는 비교적 뚜렷한 의미를 더하기도 합니다. 중요한 것은 ‘뜻이 강한가’가 아니라 사전과 문법 체계에서 접사로 분석되는가입니다.

4. 합성어 — 접사 없이 실질 형태소들이 결합한다

합성어는 둘 이상의 실질 형태소가 결합해 하나의 단어가 된 말입니다. 직접 구성 성분에 접사가 없고, 두 성분이 각각 실질 의미를 가진 요소라면 합성어로 볼 수 있습니다.

단어직접 구성 성분판별 근거
꽃집꽃 + 집두 명사가 결합해 합성어
아흔아홉아흔 + 아홉구성 요소에 접사가 없어 합성어로 분류 가능
길짐승길 + 짐승구성 요소에 접사가 없어 합성어로 분류 가능

따라서 겉으로 보기에 앞 요소가 뒤 요소를 꾸며 준다고 해서 그것을 바로 접두사로 처리해서는 안 됩니다. 먼저 그 요소가 독립된 실질 형태소인지, 실제 접사인지를 확인해야 합니다.

5. 지우개와 꽃집을 비교하면 기준이 가장 선명해진다

비교지우개꽃집
직접 구성 성분지우- / -개꽃 / 집
접사 존재있음: -개없음
구성 성분 성격어근 + 접미사실질 형태소 + 실질 형태소
최종 분류파생어합성어

이 비교가 중요한 이유는 “몇 조각으로 나뉘는가”가 아니라 “그 조각이 무엇인가”를 보여 주기 때문입니다. 두 단어 모두 둘로 나뉘지만 하나는 접사가 포함되고, 다른 하나는 그렇지 않습니다.

6. 형성 단계가 여러 번이면 ‘마지막 결합’을 먼저 본다

복합어 안에는 이미 다른 형성 과정을 거친 말이 들어갈 수 있습니다. 이때 전체 형태소의 역사를 한 번에 분류하려고 하면 파생과 합성이 섞여 보입니다. 먼저 현재 단어를 직접 만든 마지막 결합을 봅니다.

집집이

사전에서는 집집-이처럼 직접 구성 성분을 제시합니다. 마지막 단계에서 접미사 -이가 결합했으므로 최종 단어는 파생어로 읽을 수 있습니다.

벽돌집

사전에서는 벽돌-집처럼 직접 구성 성분을 제시합니다. 마지막 단계에서 두 실질 성분이 결합했으므로 최종 단계는 합성입니다.

분석 순서: 전체 형태소 나열 → 바로 파생/합성 판정이 아니라, 최종 직접 구성 성분 확인 → 그 성분에 접사가 있는지 확인 → 필요하면 내부 성분을 한 단계 더 분석하는 순서가 안정적입니다.

7. 접사인지 어근인지 헷갈리면 사전 정보를 확인한다

접사는 겉모양만 보고 항상 판별할 수 있는 것이 아닙니다. 표준국어대사전과 우리말샘은 많은 복합어에서 붙임표를 이용해 직접 구성 성분을 보여 줍니다. 예를 들어 지우-개, 꽃-집 같은 표시는 분석에 중요한 단서가 됩니다.

다만 사전이 표제어마다 ‘합성어/파생어’라는 라벨을 직접 제공하는 것은 아니며, 붙임표가 없는 단어도 있습니다. 따라서 붙임표 → 구성 성분 확인 → 구성 성분의 품사·접사 여부 검색 순서로 사용하는 것이 좋습니다.

사전 활용의 한계: 붙임표만으로 모든 단어의 분류를 확정할 수는 없습니다. 구성 성분이 음절 단위로 나뉘지 않거나 학계의 분석이 통일되지 않은 단어도 있습니다.

8. 형태 경계가 보여도 합성어·파생어를 확정하기 어려운 말이 있다

문법 문제에서 가장 위험한 습관은 모든 단어를 하나의 공식으로 반드시 분류하려는 것입니다. 국립국어원은 ‘잎새’처럼 형태 경계 자체는 확인되지만 그 자료만으로 합성어인지 파생어인지 확정하기 어렵다고 안내한 사례도 제시합니다.

또 같은 단어라도 학자에 따라 형태소 구조나 직접 구성 성분을 다르게 분석할 수 있습니다. 학교 문법에서 견해가 갈리는 사례를 만났다면 교과서·제시문·문제에서 채택한 분석 기준을 우선해야 합니다.

판별 원칙: 대표 사례는 규칙으로 익히되, 경계 사례에서는 사전과 교과서의 분석을 확인합니다. ‘접사처럼 보인다’거나 ‘뜻이 있어 보인다’는 직감만으로 확정하지 않습니다.

9. 시험에서는 이 순서로 판별하면 된다

① 이 말이 복합어인가 → ② 직접 구성 성분은 무엇인가 → ③ 그중 접사가 있는가 → ④ 접사 있으면 파생어 / 접사 없고 실질 성분끼리면 합성어 → ⑤ 경계 사례는 교과서 기준 확인

오답 습관바른 판별
형태소가 많으면 파생어라고 생각함형태소 개수보다 직접 구성 성분과 접사 유무를 봄
앞말이 뒤말을 꾸미면 접두사라고 단정함독립된 실질 형태소인지 사전에서 확인
내부에 파생이 한 번이라도 있으면 최종 단어도 파생어라고 봄최종 직접 구성 성분을 먼저 보고 마지막 형성 방식을 판단
모든 단어는 반드시 하나로 확정 가능하다고 생각함견해차가 있는 경우 교과서·제시문 기준을 우선
