형태소 분석과 품사 분석의 차이

형태소 분석은 말을 뜻을 가진 최소 단위로 나누는 일이고, 품사 분석은 단어를 문법적 성질에 따라 분류하는 일입니다. 같은 표현을 보더라도 분석 층위가 다르므로 결과가 같을 필요가 없습니다.

형태소 분석 = 내부 구조를 나누기
품사 분석 = 단어의 갈래를 분류하기
특히 조사는 단어이자 형태소로 볼 수 있지만, 어미는 형태소이되 학교 문법의 품사는 아닙니다.

1. 두 분석은 ‘대상’과 ‘결과 단위’가 다르다

표준국어대사전은 형태소를 뜻을 가진 가장 작은 말의 단위로 풀이합니다. 반면 품사는 단어를 기능·형태·의미에 따라 나눈 갈래입니다. 따라서 형태소 분석은 한 단어 안으로 더 들어가 최소 단위를 찾을 수 있지만, 품사 분석은 기본적으로 단어가 어느 문법적 갈래에 속하는지를 판단합니다.

구분형태소 분석품사 분석
핵심 질문어떤 최소 의미 단위들로 이루어졌는가?이 단어는 어떤 품사인가?
주요 결과어근·접사·어간·어미·조사 등 형태소명사·대명사·수사·동사·형용사·관형사·부사·조사·감탄사
관심 층위단어 내부까지 분석단어의 문법적 갈래

2. 형태소 분석 — 뜻이나 문법 기능을 가진 최소 단위까지 나눈다

형태소는 어휘적인 뜻뿐 아니라 시제·관계·종결처럼 문법적인 뜻을 나타내는 요소도 포함합니다. 그래서 용언의 활용형을 형태소로 분석하면 어간과 어미가 나뉩니다.

먹었다 → 먹- / -었- / -다

먹-: 중심 의미를 가진 어간

-었-: 과거를 나타내는 선어말 어미

-다: 문장을 끝맺는 어말 어미

다만 형태소 분석은 문법 이론에 따라 경계가 달라질 수 있습니다. 국립국어원도 구체적인 형태소 분석에서 견해차가 있을 수 있으므로 학생은 교과서의 분석 기준을 따르라고 안내합니다.

3. 품사 분석 — 단어를 기능·형태·의미에 따라 분류한다

품사는 형태소의 종류를 나열하는 체계가 아니라 단어의 갈래입니다. 예를 들어 ‘먹었다’는 여러 형태소로 이루어졌지만 품사는 여전히 동사 ‘먹다’의 활용형입니다. ‘예쁘게’도 문장 안에서 부사어 역할을 하더라도 품사는 형용사 ‘예쁘다’의 활용형입니다.

품사와 문장 성분도 다릅니다. ‘예쁘게’는 품사로는 형용사이지만, “옷을 예쁘게 입는다”에서는 문장 성분으로 부사어입니다.

4. 같은 문장을 세 층위로 보면 차이가 선명하다

문장 “철수가 밥을 먹었다.”를 어절·품사·형태소 층위로 나누어 보겠습니다.

층위분석 결과무엇을 보는가
어절철수가 / 밥을 / 먹었다띄어쓰기 단위
단어·품사철수(명사) + 가(조사) / 밥(명사) + 을(조사) / 먹었다(동사 활용형)단어의 문법적 갈래
형태소철수 / 가 / 밥 / 을 / 먹- / -었- / -다뜻을 가진 최소 단위

이 표에서 중요한 점은 한 어절이 반드시 한 단어인 것도 아니고, 한 단어가 반드시 한 형태소인 것도 아니라는 것입니다.

5. 조사와 어미를 보면 품사 분석의 경계가 보인다

한국어 학교 문법에서는 조사를 다른 말에 붙여 쓰지만 일반적으로 하나의 단어로 봅니다. 그래서 ‘철수가’의 ‘가’는 형태소 분석에서도 하나의 형태소이고, 품사 분석에서도 조사라는 독립된 품사입니다.

반면 어미는 용언이 활용할 때 나타나는 형태소이지만 품사로 다루지 않습니다. ‘먹었다’의 ‘-었-’, ‘-다’를 각각 품사라고 적으면 안 됩니다.

기억할 경계: 조사 = 붙여 쓰지만 단어·품사로 인정되는 경우 / 어미 = 형태소이지만 품사는 아님.

6. ‘어간’과 ‘형태소’도 항상 같은 단위는 아니다

형태소 분석에서 또 하나 조심할 점은 어간을 무조건 하나의 형태소라고 보는 것입니다. 국립국어원은 어간은 활용할 때 변하지 않는 부분이라는 개념이고, 복합어인 용언의 어간은 형태소가 둘 이상일 수 있다고 설명합니다.

고요하다 → 고요 / 하- / -다

‘고요하-’ 전체가 어간이지만 형태소 분석에서는 ‘고요’와 ‘하-’로 더 나뉠 수 있습니다. 따라서 어간 = 형태소 하나라는 공식은 성립하지 않습니다.

7. 품사와 문장 성분까지 한꺼번에 섞지 않는다

국어 문제에서는 형태소, 품사, 문장 성분이 한 문장 안에 동시에 등장할 수 있습니다. 이 세 분석은 서로 연결되지만 질문이 다릅니다.

분석질문예: 예쁘게
형태소어떤 최소 단위인가?예쁘- / -게
품사어떤 단어 갈래인가?형용사 ‘예쁘다’의 활용형
문장 성분문장 안에서 무슨 역할인가?“예쁘게 입는다”에서 부사어

8. 문제에서는 ‘무엇을 묻는지’부터 확인한다

① 형태소로 분석하시오
최소 의미 단위까지 나눕니다. 예: 갔다 → 가- / -았- / -다.
② 품사를 밝히시오
단어의 갈래를 답합니다. 예: 갔다 → 동사 ‘가다’의 활용형.
③ 조사를 찾으시오
조사는 형태소이면서 학교 문법에서는 단어·품사로 인정되므로 두 지식이 함께 필요합니다.
④ 문장 성분을 밝히시오
품사와 별개로 실제 문장 속 역할을 판단합니다.
시험 주의: 형태소 경계나 일부 분석 방식에는 견해차가 있을 수 있습니다. 문제에 교과서·제시문 기준이 주어지면 그 기준을 우선합니다.
