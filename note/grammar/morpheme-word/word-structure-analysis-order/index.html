단어 구조 분석 순서

복잡한 단어는 최소 형태소부터 전부 쪼개기보다, 가장 마지막에 결합한 두 직접 구성 성분을 먼저 찾는 편이 안전합니다. 그다음 최종 단어가 합성어인지 파생어인지 판정하고, 문제에서 요구할 때만 구성 성분 내부로 한 단계씩 더 들어갑니다.

핵심 순서
① 분석 대상이 ‘단어’인지 확인 → ② 사전에서 최종 직접 구성 성분 확인 → ③ 두 성분의 성격 확인 → ④ 최종 합성어·파생어 판정 → ⑤ 필요할 때 내부 구성 재분석 → ⑥ 형태소 분석은 마지막에 따로 수행

  5. 4단계: 내부를 한 단계 더 분석

1. 단어 구조 문제는 ‘최소 단위’보다 ‘마지막 결합’을 먼저 묻는다

형태소 분석과 단어 형성 분석은 목적이 다릅니다. 형태소 분석은 뜻을 가진 최소 단위까지 나누는 일이고, 직접 구성 성분 분석은 그 단어를 마지막으로 만들어 낸 두 구성 성분을 찾는 일입니다. 그래서 같은 단어도 분석 결과가 다르게 보일 수 있습니다.

달맞이

직접 구성 성분: 달-맞이

형태소 분석: 달-맞-이

국립국어원은 사전이 이 두 분석을 구별해 제시하는 이유를, 복합어가 어떤 성분들의 결합으로 형성되었는지 파악하기 쉽게 하기 위해서라고 설명합니다.

따라서 문제에서 ‘합성어인가 파생어인가’ 또는 ‘직접 구성 성분은 무엇인가’를 묻는다면 최소 형태소부터 나누지 않습니다. 먼저 마지막 결합을 찾습니다.

2. 1단계 — 지금 보는 것이 ‘단어’인지부터 확인한다

용언의 활용형에는 어미가 붙어 있어 형태소가 여러 개 보이지만, 어미는 단어 형성의 접사가 아닙니다. 따라서 먹었다 → 먹-/-었-/-다처럼 형태소가 여러 개라고 해서 복합어가 되는 것은 아닙니다. 먼저 분석 대상이 하나의 표제어인지, 활용된 형태인지 구별해야 합니다.

표제어 확인
사전에서 기본형을 찾습니다. 활용형이면 기본형으로 돌아가 단어 구조를 봅니다.
조사·어미 분리
조사와 어미는 문장 안에서 붙지만 파생 접사와 같은 층위로 처리하지 않습니다.
형태소 분석과 품사 분석의 차이전성 어미와 접사 ― 활용과 파생 구별

3. 2단계 — 사전에서 최종 직접 구성 성분을 먼저 찾는다

표준국어대사전은 많은 복합어에서 붙임표(-)로 최종적인 직접 구성 성분의 경계를 표시합니다. 구성 성분이 여럿이어도 가장 마지막 분석 결과만 보여 주므로 붙임표는 보통 한 번만 나타납니다.

단어사전의 최종 경계첫 판단
살얼음살-얼음살 / 얼음의 마지막 결합을 먼저 본다
단팥죽단-팥죽단 / 팥죽의 마지막 결합을 먼저 본다
벽돌집벽돌-집벽돌 / 집의 마지막 결합을 먼저 본다
집집이집집-이집집 / -이의 마지막 결합을 먼저 본다

붙임표가 없다고 반드시 단일어인 것은 아닙니다. 형태 변화 때문에 문자상의 경계를 표시하기 어려운 복합어도 있으므로, 붙임표는 매우 강한 단서이지만 유일한 기준은 아닙니다.

4. 3단계 — 두 직접 구성 성분의 성격으로 최종 유형을 판정한다

직접 구성 성분을 찾았으면 두 성분이 무엇인지 사전에서 확인합니다. 한쪽이 파생 접사라면 최종 단어는 파생어로, 접사 없이 두 실질적인 구성 성분이 결합했다면 합성어로 볼 수 있습니다.

지우개

지우- + -개. -개가 접사이므로 최종 유형은 파생어.

꽃집

꽃 + 집. 두 성분이 모두 명사이고 접사가 없으므로 최종 유형은 합성어.

집집이

집집 + -이. 최종 경계에 접미사 -이가 있으므로 전체 단어의 최종 유형은 파생어.

벽돌집

벽돌 + 집. 최종 경계에 접사가 없으므로 전체 단어의 최종 유형은 합성어.

파생어와 합성어 차이파생어 판별 ― 접사 확인하기

5. 4단계 — 문제에서 요구할 때만 내부 구성 성분을 다시 분석한다

최종 유형을 판정한 뒤, “어떤 형성 단계를 거쳤는가”까지 묻는 문제라면 직접 구성 성분 중 복잡한 쪽을 다시 한 단계 나눕니다. 이때 분석은 바깥에서 안쪽으로 들어갑니다.

집집이

1차: 집집-이 → 최종적으로 파생어

2차: 집-집 → ‘집집’ 내부에는 합성적 결합

따라서: 합성적 구성 뒤 접미사가 붙어 최종적으로 파생된 단어

달맞이

1차: 달-맞이 → 최종 직접 구성 성분에 접사가 없으므로 합성적 결합

2차: 맞-이 → ‘맞이’ 내부에서는 접미사 -이가 결합한 파생 과정

따라서: 내부에 파생된 성분이 들어 있지만 달맞이 전체의 마지막 결합은 달 + 맞이

중요: 단어 안에 접사가 들어 있다는 사실과 ‘전체 단어의 최종 유형’은 같은 질문이 아닙니다. 전체 유형은 가장 마지막 결합을 기준으로 판정합니다.

6. 형태소 분석은 최종 유형 판정과 분리해서 한다

단어의 형성 단계를 다 본 다음에, 문제가 최소 의미 단위를 요구하면 형태소 분석으로 전환합니다. 직접 구성 성분은 두 덩어리의 마지막 결합을 보여 주지만 형태소 분석은 더 작은 단위까지 들어갈 수 있습니다.

단어직접 구성 성분형태소 분석무엇을 알려 주는가
달맞이달-맞이달-맞-이마지막 결합 vs 최소 단위
집집이집집-이집-집-이최종 파생과 내부 합성
지우개지우-개지우-개직접 구성 성분과 형태소 경계가 같은 경우

같은 단어라도 질문이 “직접 구성 성분”, “형태소”, “어근과 접사”, “합성어·파생어” 중 무엇을 묻느냐에 따라 필요한 분석 깊이가 달라집니다.

7. 대표 문제 세 개를 순서대로 풀어 보기

문제 A. ‘잡아먹히다’는 합성어인가 파생어인가?

① 표제어 확인 → ‘잡아먹히다’

② 사전의 최종 분석 → 잡아먹-히다

③ -히-가 피동 접사 → 최종 유형은 파생어

④ 필요하면 ‘잡아먹-’ 내부 형성은 별도로 다시 분석

겉으로 ‘잡아 + 먹히다’처럼 자르고 싶어도 최종 직접 구성 성분은 사전의 분석을 먼저 확인해야 합니다. 국립국어원도 표준국어대사전의 `잡아먹-히다` 분석을 근거로 파생어로 볼 수 있다고 안내합니다.

문제 B. ‘땀받이’에서 -이는 접사니까 전체가 파생어인가?

① 사전의 최종 직접 구성 성분 → 땀-받이

② 먼저 땀 / 받이를 두 구성 성분으로 본다

③ ‘받이’ 내부의 -이까지 내려가는 것은 2차 분석

④ 따라서 내부 접사만 보고 전체 유형을 곧바로 결정하지 않는다

이 사례처럼 내부에 접사가 보여도 최종 직접 구성 성분이 무엇인지 먼저 확인해야 합니다. 구체적인 합성·파생 판정에는 견해차가 있을 수 있으므로 교과서 기준을 우선합니다.

문제 C. ‘덧붙이다’는 눈에 보이는 덧-부터 나누면 되는가?

표준국어대사전의 최종 직접 구성 성분 표시는 덧붙-이다입니다.

즉 처음부터 덧- / 붙- / -이-처럼 최소 단위로 펼치지 말고, 사전이 제시하는 마지막 결합부터 확인한 뒤 내부를 추가 분석합니다.

8. 실전에서는 이 6단계만 고정한다

1. 표제어를 찾는다.
활용형의 어미나 조사까지 단어 형성 요소로 세지 않는다.
2. 사전의 붙임표와 직접 구성 성분을 확인한다.
가장 마지막 결합이 무엇인지 먼저 본다.
3. 두 구성 성분을 다시 사전에서 확인한다.
명사·어근·접사 등 성격을 확인한다.
4. 최종 단어 유형을 판정한다.
접사가 직접 결합했다면 파생어, 접사 없이 실질 성분이 결합했다면 합성어로 본다.
5. 복잡한 구성 성분만 한 단계 더 분석한다.
형성 과정을 묻는 문제에서만 안쪽으로 내려간다.
6. 최소 단위를 묻는다면 마지막에 형태소 분석으로 전환한다.
직접 구성 성분 분석과 형태소 분석을 한꺼번에 섞지 않는다.
경계 사례: 직접 구성 성분이나 합성·파생 분석은 학자에 따라 달라질 수 있습니다. 사전 분석은 매우 중요한 기준이지만 모든 이론의 유일한 정답은 아니므로, 학생은 교과서와 제시문의 분석 체계를 우선합니다.
