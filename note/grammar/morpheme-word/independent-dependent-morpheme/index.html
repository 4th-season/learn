자립 형태소와 의존 형태소

형태소는 모두 뜻이나 문법적 기능을 지니지만, 문장 속에서 스스로 설 수 있는지는 서로 다릅니다. 자립 형태소와 의존 형태소는 바로 이 자립성을 기준으로 나눈 분류입니다.

자립 형태소는 다른 말에 형태적으로 기대지 않고 하나의 단위로 설 수 있는 형태소이고, 의존 형태소는 다른 형태소와 결합해야 쓰이는 형태소입니다. 이 분류에서 중요한 것은 ‘뜻이 크냐 작으냐’가 아니라 형태적으로 혼자 설 수 있느냐입니다.

1. 자립 형태소와 의존 형태소는 ‘자립성’으로 나눈다

형태소는 뜻을 가진 가장 작은 말의 단위입니다. 이 형태소를 다시 나눌 때 여러 기준을 사용할 수 있는데, 자립 형태소와 의존 형태소는 다른 말에 의존하지 않고 형태적으로 혼자 설 수 있는가를 기준으로 구별합니다.

책

‘책’은 하나의 형태소이면서 혼자 하나의 단어로 설 수 있습니다. 자립 형태소입니다.

-을

목적격 조사 ‘을’은 문법적 기능을 지니지만 앞말 없이 홀로 쓰이지 않습니다. 의존 형태소입니다.

판별 질문: “이 형태소가 뜻을 가지는가?”는 이미 형태소인지 확인하는 질문입니다. 자립·의존을 가를 때는 그다음 질문인 “다른 형태소에 붙지 않고 형태적으로 설 수 있는가?”를 봅니다.

2. 자립 형태소 — 다른 형태소에 붙지 않고 설 수 있다

자립 형태소는 하나의 단어 전체가 곧 하나의 형태소인 경우에서 쉽게 찾을 수 있습니다. ‘하늘’, ‘사람’, ‘책’, ‘오늘’, ‘우리’처럼 다른 형태소가 붙지 않은 상태로 문장에서 하나의 단위로 쓰이는 말이 대표적입니다.

예품사·성격자립 형태소인 이유
하늘명사다른 형태소에 붙지 않고 단어로 설 수 있음
우리대명사독립된 단어로 쓰일 수 있음
오늘명사·부사적 쓰임그 자체가 하나의 형태소이자 독립 단어가 될 수 있음
아주부사뒤 말을 꾸미지만 형태적으로 다른 형태소에 붙어 있지 않음

여기서 ‘혼자 설 수 있다’는 말은 실제 대화에서 그 말 하나만 외쳐도 완전한 문장이 된다는 뜻이 아닙니다. 형태적으로 다른 형태소에 결합된 채로만 존재하는가를 보는 기준입니다.

3. 의존 형태소 — 반드시 다른 형태소와 결합해 쓰인다

의존 형태소는 의미나 기능이 있어도 단독으로 하나의 단어처럼 쓰이지 못합니다. 학교 문법에서 대표적인 의존 형태소에는 용언의 어간, 조사, 어미, 접사가 있습니다.

종류예왜 의존하는가
용언의 어간먹-, 읽-, 맑-활용할 때 어미와 결합해야 실제 형태로 쓰임
조사이/가, 을/를, 은/는체언 등 앞말에 붙어 관계를 나타냄
어미-다, -고, -었-, -면용언 어간 뒤에 붙어 문법 기능을 나타냄
접사풋-, 맨-, -님, -스럽-어근에 붙어 새로운 단어나 의미를 만듦
주의: 의존 형태소라고 해서 뜻이 없는 것은 아닙니다. ‘먹-’은 분명 동작의 의미를 가지고, ‘-었-’은 과거와 관련된 문법적 의미를 나타냅니다. 자립성은 의미의 유무와 다른 기준입니다.

4. ‘먹-’은 뜻이 분명한데 왜 의존 형태소인가

용언의 어간은 자립·의존 분류에서 가장 자주 틀리는 사례입니다. ‘먹-’, ‘읽-’, ‘맑-’은 동작이나 상태라는 실질적인 의미를 지닙니다. 그래서 자립 형태소처럼 느껴지지만 실제 문장에서는 어미와 결합하여 나타납니다.

먹다 → 먹- / -다

먹-: 먹는 동작이라는 실질 의미를 지니지만 어미와 결합하여 쓰이는 의존 형태소

-다: 문장을 끝맺는 기능을 나타내며 어간 뒤에 붙는 의존 형태소

따라서 실질적인 뜻이 있다 = 자립 형태소라는 공식은 성립하지 않습니다. 용언의 어간은 실질 형태소이면서 동시에 의존 형태소가 될 수 있습니다.

5. ‘의존 명사’는 이름과 달리 자립 형태소로 분류한다

‘것’, ‘수’, ‘뿐’ 같은 의존 명사는 앞에 관형어가 필요한 경우가 많아 이름 그대로 ‘의존적’입니다. 그런데 이때의 의존성은 문장 구성에서 앞말을 필요로 하는 통사적 의존성입니다. 자립 형태소와 의존 형태소를 가르는 형태론적 자립성과는 층위가 다릅니다.

할 수 있다

‘수’는 앞의 ‘할’이라는 관형어가 필요하지만 조사나 어미처럼 다른 형태소에 붙여 쓰는 요소는 아닙니다.

아는 것이 힘이다

‘것’은 앞 관형어의 수식을 받지만 명사 기능을 하며 형태상 하나의 단어로 취급됩니다.

학교 문법의 일반적 분류: 의존 명사는 통사적으로는 의존적이지만 형태상으로는 자립적이므로 자립 형태소로 분류합니다. 이름에 ‘의존’이 들어 있다고 곧바로 의존 형태소로 판단하면 안 됩니다.

6. 자립·의존과 실질·형식은 서로 다른 두 분류다

형태소를 공부할 때 가장 중요한 것은 두 분류 기준을 섞지 않는 것입니다. 자립/의존은 형태적 자립성을 보고, 실질/형식은 의미의 성격과 기능을 봅니다.

형태소자립성 기준의미 성격 기준이유
책자립실질홀로 단어로 서고 대상을 가리킴
먹-의존실질어미가 필요하지만 동작 의미를 가짐
-을의존형식앞말에 붙어 문법적 관계를 표시함
-었-의존형식어간 뒤에 붙어 문법적 의미를 나타냄
것(의존 명사)자립실질통사적으로는 앞말을 필요로 하지만 형태론적으로는 자립적인 명사

이 표에서 보듯 ‘자립 형태소는 모두 실질 형태소’로 설명하는 학교 문법의 일반적 체계와 달리, 의존 형태소 안에는 실질 형태소와 형식 형태소가 모두 존재합니다. 그래서 두 기준을 각각 적용해야 합니다.

7. 실제 문장은 ‘형태소 분리 → 자립성 판단’ 순서로 본다

예문 1. 철수가 책을 읽었다.

형태소 분석: 철수 / 가 / 책 / 을 / 읽- / -었- / -다

자립 형태소: 철수, 책

의존 형태소: 가, 을, 읽-, -었-, -다

‘철수’와 ‘책’은 독립된 명사이고, 조사는 앞말에 붙으며, 용언 어간과 어미는 서로 결합해 활용형을 이루므로 이렇게 나뉩니다.

예문 2. 나는 할 수 있다.

형태소 분석: 나 / 는 / 하- / -ㄹ / 수 / 있- / -다

자립 형태소: 나, 수

의존 형태소: 는, 하-, -ㄹ, 있-, -다

이 예문에서는 의존 명사 ‘수’가 핵심입니다. 문장 안에서는 앞의 관형어 ‘할’을 필요로 하지만, 형태소 분류에서는 자립 형태소로 처리하는 것이 일반적입니다.

8. 자주 틀리는 판단 네 가지

① 뜻이 있으면 자립 형태소다?

아닙니다. ‘읽-’처럼 실질 의미가 있어도 어미와 결합해야 하면 의존 형태소입니다.

② 앞말이 필요하면 모두 의존 형태소다?

아닙니다. 의존 명사는 통사적으로 앞말을 필요로 하지만 형태론적으로는 자립 형태소로 봅니다.

③ 조사도 단어인데 자립 형태소인가?

아닙니다. 학교 문법에서 조사를 단어로 인정하더라도 형태소 분류에서는 앞말에 붙어 쓰이는 의존 형태소입니다.

④ 자립·의존과 실질·형식은 같은 분류다?

아닙니다. 서로 다른 기준이므로 한 형태소에 두 분류를 각각 적용해야 합니다.

분석 차이 주의: 형태소 분석은 문법 이론이나 교과서에 따라 세부 견해가 달라질 수 있습니다. 학교 시험에서는 교과서나 제시문의 분석 기준을 우선하되, 자립 형태소·의존 형태소의 기본 정의와 대표 범주는 위 기준으로 잡는 것이 안전합니다.
