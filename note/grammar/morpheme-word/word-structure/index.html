단어의 구조

단어를 분석할 때는 작은 조각을 많이 찾는 것만으로 충분하지 않습니다. 무엇이 중심 의미를 이루는지, 무엇이 새 단어를 만드는 요소인지, 그리고 가장 마지막에 어떤 두 성분이 결합했는지를 함께 봐야 단어 형성의 구조가 드러납니다.

어근은 단어의 실질적 의미를 나타내는 중심 부분이고, 접사는 어근이나 단어에 붙어 새로운 단어를 만드는 부분입니다. 직접 구성 성분은 둘 이상의 형태소가 결합한 단어를 가장 마지막 결합 단계에서 둘로 나누었을 때 얻는 두 성분입니다. 형태소 분석과 직접 구성 성분 분석은 같은 작업이 아닙니다.
목차
  1. 단어 구조에서 세 가지를 구별해야 하는 이유
  2. 어근은 무엇인가
  3. 접사는 무엇인가
  4. 어근과 어간은 어떻게 다른가
  5. 직접 구성 성분은 무엇인가

  8. 조사와 어미는 왜 접사가 아닌가

1. 단어 구조는 ‘몇 개로 나뉘는가’보다 ‘어떻게 만들어졌는가’를 본다

형태소 분석은 단어를 뜻을 가진 최소 단위까지 나누는 작업입니다. 반면 단어 구조 분석은 그 작은 단위들이 어떤 순서로 결합해 현재의 단어가 되었는지를 읽는 작업입니다. 그래서 형태소의 개수가 같아도 내부 결합 구조는 다를 수 있습니다.

어근중심 뜻을 담당하는 부분을 찾는다.
접사새 단어를 만드는 부가 성분이 있는지 본다.
직접 구성 성분가장 마지막에 결합한 두 덩어리를 찾는다.
핵심 질문: “이 단어에 형태소가 몇 개인가?”와 “이 단어는 가장 마지막에 무엇과 무엇이 결합해 만들어졌는가?”는 서로 다른 질문입니다.

2. 어근 — 단어의 실질적 의미를 나타내는 중심 부분

어근은 단어를 형성하는 관점에서 쓰는 용어입니다. 단어 안에서 실질적인 의미의 중심을 담당하며, 하나의 어근만으로 단어가 되기도 하고 다른 어근이나 접사와 결합하기도 합니다.

지우개

‘지우-’가 ‘지우다’의 중심 의미를 나타내므로 어근입니다. 뒤의 ‘-개’는 새 명사를 만드는 접미사입니다.

힘들다

단어 형성의 관점에서는 ‘힘’과 ‘들-’이 각각 어근입니다. 둘이 결합해 하나의 용언을 이룹니다.

어근은 반드시 혼자 단어로 쓰여야 하는 것은 아닙니다. ‘지우-’, ‘들-’처럼 홀로 쓰이기 어려워도 단어 형성에서 실질 의미의 중심을 담당하면 어근이 될 수 있습니다.

주의: ‘어근이 하나이면 파생어, 둘이면 합성어’처럼 개수만으로 최종 분류를 결정하면 안 됩니다. 복잡한 단어에서는 가장 마지막 결합 단계인 직접 구성 성분을 먼저 확인해야 합니다.

3. 접사 — 다른 어근이나 단어에 붙어 새로운 단어를 만든다

접사는 단독으로 쓰이지 않고 다른 어근이나 단어에 붙어 새로운 단어를 구성하는 부분입니다. 앞에 붙으면 접두사, 뒤에 붙으면 접미사라고 합니다.

구분결합 위치대표 구조핵심 기능
접두사어근 앞접두사 + 어근뜻을 더하거나 제한하며 새 단어를 만듦
접미사어근 뒤어근 + 접미사뜻을 더하거나 품사를 바꾸며 새 단어를 만듦

지우개 → 지우- + -개

지우-: 어근

-개: 접미사

직접 구성 성분 가운데 하나가 접사이므로 ‘지우개’는 파생 구조로 설명됩니다.

중요한 것은 붙어 쓰이는 모든 요소가 접사는 아니라는 점입니다. 조사와 어미도 다른 말에 붙지만, 접사는 단어를 새로 만드는 조어론적 요소이고 조사·어미는 품사나 활용 체계에서 다루는 문법 요소입니다.

4. 어근과 어간은 같은 말이 아니다

어근과 어간은 비슷해 보여도 질문 자체가 다릅니다. 어근은 단어 형성을 볼 때 쓰고, 어간은 용언의 활용을 볼 때 씁니다. 어떤 단어에서는 둘이 같은 모양일 수 있지만 항상 같은 것은 아닙니다.

힘들다

어근: 힘 / 들- → 단어가 어떻게 만들어졌는지를 분석

어간: 힘들- → 힘들다, 힘들고, 힘들면처럼 활용할 때 변하지 않는 부분

단어 형성 문제

어근·접사·직접 구성 성분을 중심으로 본다.

활용 문제

어간·어미를 중심으로 본다.

시험에서 자주 생기는 오류: 어근과 어간을 무조건 같은 범위로 표시하면 복합어·파생어 분석에서 틀리기 쉽습니다. 먼저 문제가 ‘단어 형성’을 묻는지 ‘활용’을 묻는지 확인합니다.

5. 직접 구성 성분 — 가장 마지막에 결합한 두 성분을 찾는다

직접 구성 성분은 둘 이상의 형태소가 결합한 단어를 구성하고 있는 바로 아래 단계의 두 요소입니다. 쉽게 말하면 그 단어를 형성 과정에 따라 처음 한 번만 둘로 나누었을 때 얻는 두 덩어리입니다.

달맞이 → 달 + 맞이

‘달맞이’를 형태소 단위까지 나누면 달 / 맞- / -이가 됩니다. 하지만 직접 구성 성분은 달과 이미 만들어진 단어 맞이입니다.

이 차이가 중요합니다. ‘맞이’ 내부에는 어근 ‘맞-’과 접미사 ‘-이’가 있지만, ‘달맞이’ 전체를 가장 마지막 형성 단계에서 보면 ‘달’과 ‘맞이’가 직접 결합한 구조입니다.

구조 읽기: 최소 단위까지 한 번에 쪼개는 대신, 가장 나중에 만들어진 경계부터 바깥→안쪽 순서로 분석하면 복잡한 단어의 구조가 훨씬 잘 보입니다.

6. 형태소 분석과 직접 구성 성분 분석은 결과가 다를 수 있다

단어형태소 분석직접 구성 성분무엇을 보여 주는가
지우개지우- / -개지우- + -개어근과 접미사가 바로 결합한 구조
달맞이달 / 맞- / -이달 + 맞이‘맞이’가 먼저 만들어진 뒤 ‘달’과 결합한 구조
젊은이분석 체계에 따라 세부 형태소 표시는 달라질 수 있음젊은 + 이(사람)직접 구성 성분에 접사가 없다는 점을 확인

‘젊은이’는 직접 구성 성분을 ‘젊은’과 사람을 뜻하는 ‘이’로 분석할 수 있고, 둘 가운데 접사가 없으므로 합성어로 설명됩니다. 반면 ‘지우개’는 직접 구성 성분 가운데 ‘-개’가 접사이므로 파생어입니다.

중요: 단어의 모든 내부 요소를 한 줄에 늘어놓은 뒤 “접사가 하나라도 보이면 파생어”라고 판단하면 복합적인 단어에서 오류가 생길 수 있습니다. 최종 단어의 분류는 가장 직접적으로 결합한 성분을 먼저 봅니다.

7. 단어 구조는 이 세 단계로 분석하면 안정적이다

1단계 · 최소 단위 확인형태소를 가능한 범위에서 나누어 어떤 재료가 있는지 본다.
2단계 · 역할 확인각 성분이 어근인지 접사인지, 또는 다른 층위의 요소인지 구별한다.
3단계 · 결합 단계 확인가장 마지막에 결합한 두 직접 구성 성분을 정한다.

예: 달맞이

① 형태소: 달 / 맞- / -이

② 내부 구조: 맞- + -이 → 맞이

③ 직접 구성 성분: 달 + 맞이 → 달맞이

이렇게 단계적으로 보면 ‘달맞이’ 안에 접미사 ‘-이’가 있다는 사실과, ‘달맞이’ 전체의 마지막 결합이 ‘달 + 맞이’라는 사실을 동시에 설명할 수 있습니다.

8. 조사와 어미는 붙어 있어도 접사가 아니다

접사·조사·어미는 모두 다른 요소와 결합해서 나타나기 때문에 겉모양만 보면 헷갈립니다. 그러나 문법에서 속한 층위가 다릅니다.

요소분석 층위하는 일새 단어 형성
접사단어 형성어근이나 단어에 붙어 새 단어를 만듦예
조사품사·문장 관계체언 등과 결합해 문법 관계나 뜻을 표시아니오
어미용언 활용어간에 붙어 시제·종결·연결 등의 기능을 나타냄아니오

따라서 ‘철수가’의 ‘가’를 접사라고 하거나, ‘먹었다’의 ‘-었-’, ‘-다’를 접사라고 하면 안 됩니다. 접사는 새 단어를 형성하는가가 핵심 기준입니다.

9. 사전의 붙임표는 직접 구성 성분을 읽는 단서가 된다

표준국어대사전과 우리말샘은 많은 복합어에서 붙임표를 이용해 직접 구성 성분의 경계를 보여 줍니다. 예를 들어 ‘지우-개’처럼 제시된 경우 두 직접 구성 성분을 확인한 뒤 각각을 다시 사전에서 찾아 접사인지 단어인지 판단할 수 있습니다.

지우-개

‘-개’가 접사임을 확인하면 파생 구조라는 판단으로 이어집니다.

꽃-집

두 성분이 모두 명사라면 어근끼리 결합한 합성 구조로 판단할 수 있습니다.

다만 사전의 붙임표만으로 모든 단어를 자동 판정할 수 있는 것은 아닙니다. 음절 경계로 직접 구성 성분을 표시하기 어려운 경우도 있고, 같은 단어의 세부 분석이 학자나 문법 체계에 따라 달라질 수도 있습니다.

학습 기준: 사전 표기를 중요한 근거로 활용하되, 교과서나 제시문이 특정한 분석 방식을 제시한 문제에서는 그 체계를 우선합니다.

10. 단어 구조 문제에서 자주 틀리는 네 가지

① 형태소 수만 센다

형태소가 세 개라고 해서 최종 단어 형성 방식을 바로 결정할 수 없습니다. 직접 구성 성분을 봐야 합니다.

② 어근과 어간을 같은 말로 본다

어근은 단어 형성, 어간은 활용을 설명하는 용어입니다.

③ 붙는 요소를 모두 접사로 본다

조사와 어미는 접사와 다른 문법 층위에 있습니다.

④ 내부 접사 하나만 보고 최종 분류한다

복잡한 단어는 가장 마지막 결합 단계의 직접 구성 성분을 먼저 확인해야 합니다.

단어 구조 분석의 핵심은 “최소 단위까지 나누기 → 각 성분의 역할 확인 → 가장 마지막 결합 단계 찾기”입니다. 어근·접사·직접 구성 성분을 같은 층위의 세 이름으로 외우지 말고, 각각이 어떤 질문에 답하는 개념인지 구별하면 단어 형성 문제의 기준이 선명해집니다.
