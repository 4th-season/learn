통사적 합성어와 비통사적 합성어

합성어를 이루는 두 구성 성분의 결합이 한국어에서 평소 만드는 구나 문장의 방식과 같으면 통사적 합성어, 그 방식과 다르면 비통사적 합성어로 볼 수 있습니다. 핵심은 형태를 외우는 것이 아니라 ‘이 결합을 문장 속에서도 자연스럽게 만들 수 있는가’를 확인하는 데 있습니다.

통사적 합성어 = 두 어기의 결합이 일반적인 통사적 구를 이루는 방식과 같은 합성어
비통사적 합성어 = 두 어기의 결합이 일반적인 통사적 구를 이루는 방식과 다른 합성어

다만 이 분류는 조어 분석에 따라 견해가 달라질 수 있으므로, 학생은 교과서와 제시문의 분석 기준을 우선해야 합니다.

1. 통사적·비통사적 분류는 ‘합성어’ 안에서 하는 분류다

통사적 합성어와 비통사적 합성어를 구별하기 전에 그 말이 먼저 합성어인지 확인해야 합니다. 합성어는 둘 이상의 실질적인 구성 성분이 결합한 단어이고, 파생어는 접사가 결합한 단어입니다. 따라서 접사가 보인다는 이유만으로 통사적·비통사적 합성어를 바로 묻는 것은 분석 순서가 뒤바뀐 것입니다.

① 직접 구성 성분을 찾는다.
가장 마지막에 무엇과 무엇이 결합했는지 확인합니다.
② 최종 단어가 합성어인지 파생어인지 판정한다.
직접 구성 성분에 접사가 포함되는지 확인합니다.
③ 합성어라면 두 구성 성분의 결합 방식을 본다.
일반적인 구·문장 구성과 같은지 비교합니다.
단어의 구조 ― 어근·접사·직접 구성 성분파생어와 합성어 차이

2. 통사적 합성어 — 문장 속에서도 만들 수 있는 결합 방식

통사적 합성어는 두 구성 성분의 결합 방식이 한국어에서 실제 구나 문장을 만드는 일반적인 방식과 같은 합성어입니다. 단어로 굳어 붙여 쓰이더라도, 그 내부 관계를 자연스러운 구나 문장으로 풀어낼 수 있습니다.

새잎

관형사 ‘새’ + 명사 ‘잎’. ‘새 잎’과 같은 관형사+명사 결합은 일반적인 통사적 구성입니다. 국립국어원도 ‘새잎’을 통사적 합성어로 볼 수 있다고 안내합니다.

딴것

관형사 ‘딴’ + 의존 명사 ‘것’. 관형사와 의존 명사가 결합하는 방식 자체가 일반적인 통사적 구와 같으므로 통사적 합성어로 설명됩니다.

샘솟다

‘샘이 솟다’라는 주어-서술어 관계로 환언할 수 있습니다. 명사 ‘샘’과 동사 ‘솟다’의 관계가 문장 구성 방식과 같다는 점이 핵심입니다.

볶음밥

명사 ‘볶음’ + 명사 ‘밥’의 결합으로 볼 수 있습니다. 명사가 다른 명사를 앞에서 수식하는 명사+명사 구조는 한국어에서 가능한 통사적 구성입니다.

통사적이라는 말은 ‘띄어 써야 한다’는 뜻이 아닙니다. 이미 하나의 단어로 굳어진 합성어는 붙여 쓰지만, 내부 구성 방식이 통사적인 구와 같다는 뜻입니다.

3. 비통사적 합성어 — 문장에서는 그대로 만들기 어려운 결합 방식

비통사적 합성어는 두 어기의 결합이 일반적인 통사적 구를 만드는 방식과 다른 합성어입니다. 우리말샘의 설명을 인용한 국립국어원 답변에서는 ‘접칼’, ‘오르내리다’를 대표적인 예로 제시합니다.

접칼

‘접는 칼’처럼 문장에서는 용언 어간 뒤에 관형사형 어미가 필요합니다. 그런데 합성어 안에서는 ‘접-’과 ‘칼’이 바로 결합하므로 일반적인 구 구성과 다릅니다.

오르내리다

문장에서는 ‘오르고 내리다’처럼 연결 어미가 필요하지만, 단어 내부에서는 ‘오르-’와 ‘내리-’가 직접 결합한 것으로 분석할 수 있어 비통사적 합성어의 전형적인 설명에 쓰입니다.

볼록거울

부사 ‘볼록’이 명사 ‘거울’을 바로 수식하는 구조입니다. 일반적인 구라면 ‘볼록한 거울’처럼 관형형이 자연스럽기 때문에 비통사적 합성어로 볼 수 있습니다.

어둑새벽

‘어둑-’ 계열의 어근이 명사 ‘새벽’과 직접 결합한 구조로 설명됩니다. 국립국어원은 어근에 바로 명사가 붙는 구성은 한국어의 일반적인 문장 구성 원리와 다르다고 설명합니다.

4. 대표 유형은 ‘품사 공식’보다 통사 관계로 이해한다

구성예일반적인 구·문장으로 풀기판단
관형사 + 명사새잎새 잎통사적
관형사 + 의존 명사딴것딴 것통사적
주어 + 서술어 관계샘솟다샘이 솟다통사적
명사 + 명사볶음밥볶음 + 밥통사적
용언 어간 + 명사접칼접는 칼비통사적
용언 어간 + 용언 어간오르내리다오르고 내리다비통사적
부사 + 명사볼록거울볼록한 거울비통사적
품사 배열만 암기하면 위험합니다. 같은 표면 형태라도 역사적 형성과 직접 구성 성분 분석에 따라 다른 설명이 가능할 수 있습니다. ‘어미가 보이지 않는다’는 사실 하나만으로 자동 판정하지 말고, 실제로 어떤 통사 관계를 복원할 수 있는지 확인해야 합니다.

5. ‘덮밥’과 ‘연어덮밥’은 분석 층위가 다르다

복잡한 합성어는 내부 단어 하나의 성격을 전체 단어에 그대로 옮겨 붙이면 안 됩니다. 예를 들어 ‘덮밥’은 일반적으로 ‘덮-+밥’처럼 관형사형 어미 없이 용언 어간과 명사가 결합한 비통사적 합성어로 설명됩니다. 그러나 ‘연어덮밥’의 최종 직접 구성 성분은 연어 + 덮밥입니다.

덮밥 → 내부에서는 비통사적 합성 구조
연어 + 덮밥 → 최종 결합은 명사 + 명사

국립국어원은 ‘연어덮밥’에서 ‘연어’가 ‘덮밥’을 수식하는 명사+명사 구조를 기준으로 통사적 합성어로 본다고 답했습니다. 즉 내부 구성 성분의 성격과 전체 단어의 최종 결합 방식을 분리해서 봐야 합니다.

이 원리는 앞서 배운 여러 단계의 단어 형성과 같습니다. 전체 단어를 분류할 때는 최종 직접 구성 성분을 먼저 본다는 원칙이 여기에서도 중요합니다.

여러 단계의 단어 형성 ― 파생 후 합성과 합성 후 파생

6. 용언 합성어는 역사적 어미가 숨어 있을 수 있다

용언끼리 결합한 합성어는 특히 단정하기 어렵습니다. 현재 표면에 연결 어미가 보이지 않아도 역사적으로는 연결 어미가 결합한 형태가 줄어든 것일 수 있기 때문입니다.

나가다: 나- + -아 + 가- → 나가다

국립국어원은 ‘나가다’를 어원적으로 ‘나-+-아+가-’에서 온 것으로 설명하며, 두 용언 사이에 연결 어미가 있는 구조이므로 통사적 합성어로 볼 수 있다고 안내합니다. 현재 글자 모양만 보면 ‘나-+가-’처럼 보이지만 역사 정보까지 확인하면 분석이 달라질 수 있습니다.

떠먹다: 뜨- + -어 + 먹- → 떠먹다

‘떠먹다’ 역시 ‘떠서 먹다’의 연결 관계가 단어 형성에 반영된 것으로 설명되어 통사적 합성어로 안내됩니다.

따라서 용언 합성어는 ‘연결 어미가 눈에 보이느냐’보다 실제 형성 과정과 통사 관계를 봐야 합니다.

7. ‘깨물다·건너뛰다’처럼 두 분석이 가능한 말도 있다

통사적·비통사적 합성어 분류는 모든 단어에 하나의 절대 답이 고정되어 있는 영역이 아닙니다. 국립국어원은 ‘깨물다’와 ‘건너뛰다’를 어간+어간의 직접 결합으로 보면 비통사적으로 볼 수 있지만, 첫 어간 뒤에 연결 어미 ‘-어’가 결합해 실현된 것으로 보면 통사적으로도 분석할 수 있다고 설명합니다.

또 ‘꿰뚫다’, ‘놀거리’, ‘내리치다’ 등도 역사적 형성과 문법 이론에 따라 설명이 달라질 수 있다는 답변이 있습니다. 이런 사례에서는 다음 원칙이 가장 안전합니다.

시험·학교 문법에서는 교과서와 제시문의 분석 기준을 우선합니다. 국립국어원 온라인가나다도 통사적·비통사적 합성어 분류에는 문법적 견해차가 있을 수 있다고 반복해서 안내합니다.

8. 문제에서 판단하는 순서

1단계 ― 한 단어인지 확인
단순한 구인지 이미 굳어진 합성어인지 사전과 문맥을 확인합니다.
2단계 ― 직접 구성 성분 찾기
가장 마지막에 결합한 두 요소를 먼저 나눕니다.
3단계 ― 자연스러운 구·문장으로 풀기
조사·관형사형 어미·연결 어미 등을 포함한 일반적인 한국어 구성이 그대로 복원되는지 봅니다.
4단계 ― 통사 관계 비교
같은 방식이면 통사적, 어미가 비정상적으로 빠지거나 일반 문장에서는 만들기 어려운 결합이면 비통사적 가능성이 큽니다.
5단계 ― 사전·어원·교과서 확인
용언 합성어와 경계 사례는 역사 정보나 분석 견해가 중요하므로 단정하지 않습니다.
한 문장으로 정리하면, “합성어 내부의 결합을 평범한 한국어 구나 문장으로 그대로 만들 수 있는가?”가 통사적·비통사적 합성어를 구별하는 출발점입니다. 다만 최종 판정은 직접 구성 성분과 어원·교과서의 분석까지 함께 확인해야 합니다.
