단일어와 복합어 차이

단어를 몇 개의 글자나 형태소로 나눌 수 있는지만 세면 단일어와 복합어를 자주 잘못 판단합니다. 핵심은 그 단어가 어떤 단어 형성 요소의 결합으로 만들어졌는지를 보는 것입니다.

단일어는 단어 형성상 하나의 실질적 중심을 가진 말이고, 복합어는 어근에 접사가 붙거나 둘 이상의 실질적 요소가 결합해 만들어진 말입니다. 따라서 형태소가 두 개 이상 보인다고 곧바로 복합어가 되는 것은 아닙니다.

1. 단일어와 복합어는 ‘단어가 어떻게 만들어졌는가’를 묻는다

단일어와 복합어는 단어의 길이, 글자 수, 발음의 복잡성을 기준으로 나누는 개념이 아닙니다. 단어 형성의 관점에서 내부 구조가 하나의 중심 요소로 이루어졌는지, 둘 이상의 형성 요소가 결합했는지를 묻습니다.

단일어

하늘, 땅, 밥처럼 단어 형성상 하나의 실질 형태소를 중심으로 이루어진 말입니다.

복합어

덧신, 먹이처럼 어근에 접사가 붙거나 집안, 공부방처럼 둘 이상의 실질 형태소가 결합한 말입니다.

핵심 질문: “몇 형태소인가?”보다 먼저 “새 단어를 만드는 결합이 있었는가?”를 확인해야 합니다.

2. 형태소 수만 세면 왜 틀리는가 — ‘먹다’도 두 형태소지만 단일어다

‘먹다’를 형태소로 나누면 먹- / -다입니다. 겉으로는 두 형태소이므로 복합어처럼 보일 수 있습니다. 그러나 ‘-다’는 새 단어를 만드는 접사가 아니라 용언을 활용시키는 어미입니다. 어미는 단일어와 복합어를 나누는 조어적 기준이 아닙니다.

먹다 → 먹- + -다

먹-: 단어의 실질적 의미를 담당하는 어간·어근

-다: 기본형을 만드는 종결 어미. 새 단어를 만드는 파생 접사가 아님

판정: 먹다는 단어 형성상 단일어

‘가다’, ‘마시다’, ‘푸르다’도 같은 원리로 볼 수 있습니다. 형태소 분석에서는 어간과 어미로 나뉘지만, 어미를 제외한 단어 형성 구조에 파생 접사나 별개의 어근 결합이 없으므로 일반적으로 단일어로 처리합니다.

주의: “형태소가 하나면 단일어, 둘 이상이면 복합어”라는 식의 기계적 공식은 용언 활용형에서 바로 무너집니다. 형태소 분석과 조어 분석은 서로 다른 질문입니다.

3. 단일어 — 단어 형성상 더 나눌 결합 구조가 없는 말

단일어는 사전적으로 하나의 실질 형태소로 된 말입니다. 학교 문법에서는 이를 이해하기 쉽게 하나의 어근으로 이루어진 단어라고 설명하는 경우가 많습니다.

예분석할 때 볼 점판정
하늘현대 국어의 단어 형성상 별도의 접사·어근 결합을 설정하지 않음단일어
밥하나의 실질 형태소단일어
오이음절은 둘이지만 단어 형성상 하나의 단위로 봄단일어
먹다먹-+-다로 형태소 분석되지만 -다는 어미단일어

따라서 음절이 많다, 글자가 길다, 형태소 분석에서 어미가 따로 나온다는 사실은 복합어의 충분조건이 아닙니다.

4. 복합어 — 새 단어를 만드는 결합 구조가 있는 말

복합어는 단어 내부에 단어 형성과 직접 관련된 결합이 있는 말입니다. 크게 두 방식이 있습니다.

어근 + 접사

덧- + 신 → 덧신, 먹- + -이 → 먹이처럼 파생 접사가 결합합니다.

실질 요소 + 실질 요소

집 + 안 → 집안, 공부 + 방 → 공부방처럼 둘 이상의 실질적 요소가 결합합니다.

이 두 방식에 따라 복합어는 다시 파생어와 합성어로 나뉩니다.

5. 복합어는 합성어와 파생어로 나뉜다

구분직접 구성 성분의 성격예
합성어접사 없이 실질적 성분들이 결합꽃+집 → 꽃집, 집+안 → 집안
파생어직접 구성 성분 가운데 파생 접사가 포함됨지우-+-개 → 지우개, 덧-+신 → 덧신

중요한 것은 단어를 무조건 최소 형태소까지 전부 쪼갠 뒤 개수를 세는 것이 아닙니다. 가장 마지막에 어떤 두 요소가 결합해 현재 단어가 되었는지를 확인하면 합성어·파생어 판별이 더 안정적입니다.

6. 직접 구성 성분을 보면 단일어와 복합어의 경계가 선명해진다

복합어는 내부에 결합 구조가 있으므로 직접 구성 성분을 설정할 수 있습니다. 사전에서 ‘지우-개’, ‘꽃-집’처럼 붙임표가 제시되는 경우는 그 결합 구조를 파악하는 데 도움이 됩니다.

지우개

직접 구성 성분은 지우-와 -개입니다. -개가 접사이므로 파생어, 따라서 복합어입니다.

꽃집

직접 구성 성분은 꽃과 집입니다. 두 성분이 모두 실질적 단어이므로 합성어, 따라서 복합어입니다.

반대로 단일어는 현대 국어의 단어 형성 체계에서 이러한 결합 구조를 따로 설정하지 않는 말입니다. 어원적으로 여러 요소가 있었더라도 오늘날 화자가 그 구조를 분석하기 어렵다면 공시적으로 단일어로 처리될 수 있습니다.

7. 헷갈리는 사례는 ‘어미·어원·분석 체계’를 따로 본다

먹다와 먹이

먹다: 먹- + -다. -다는 어미이므로 단어 형성상 단일어입니다.

먹이: 먹- + -이. -이는 새 명사를 만드는 접미사이므로 파생어이자 복합어입니다.

오이와 대나무

‘오이’는 음절이 둘이지만 단일어입니다. 반면 ‘대나무’는 실질 형태소들이 결합한 합성어로 분석되어 복합어입니다. 단어의 길이나 음절 수가 아니라 조어 구조가 기준이라는 점을 보여 줍니다.

한자어·외래어·오래된 말

한자어의 경우 각 한자를 형태소로 인정할지에 따라 단일어·합성어 판단이 달라질 수 있고, 외래어도 내부 요소가 현대 국어에서 의미 단위로 분석되는지에 따라 복합어로 볼 수 있습니다. 또 오래된 단어는 역사적으로 복합 구조였어도 오늘날 그 구조가 투명하지 않으면 단일어로 볼 수 있습니다.

시험 기준: 조어 분석에 견해 차이가 있는 사례를 문제에서 다룬다면 교과서·수업·제시문이 채택한 분석 체계를 우선합니다. 사전의 붙임표도 유용한 단서이지만 모든 단어의 단일어·복합어 여부를 자동으로 확정하는 표시는 아닙니다.

8. 단일어와 복합어를 판단하는 가장 안전한 순서

순서질문판단
1지금 나누려는 것이 형태소 분석인가, 단어 형성 분석인가?조어 문제라면 어미를 단어 형성 요소처럼 세지 않음
2파생 접사가 결합했는가?그렇다면 파생어 → 복합어
3둘 이상의 실질적 어근·단어가 결합했는가?그렇다면 합성어 → 복합어
4그런 결합 구조가 없는가?단일어
5분석이 논쟁적인가?사전 정보와 교과서·제시문 기준 확인
결국 단일어와 복합어의 차이는 형태소를 몇 개 셀 수 있느냐가 아니라, 새 단어를 만드는 결합 구조가 있느냐에 있습니다. 이 기준을 세우면 먹다·먹이, 오이·대나무처럼 겉모양이 비슷하거나 길이가 다른 사례도 안정적으로 구별할 수 있습니다.
