형태소와 단어

문장을 띄어쓰기 단위로만 보면 보이지 않는 구조가 있습니다. 단어를 더 작은 의미 단위로 나누면 조사·어미·어간의 역할과 단어가 만들어지는 원리가 드러납니다.

형태소는 뜻을 가진 가장 작은 말의 단위이고, 단어는 독립적으로 쓰이는 말의 최소 단위를 중심으로 정한 문법 단위입니다. 둘은 크기만 다른 같은 개념이 아닙니다. 형태소는 단어 내부까지 분석하지만, 단어는 문장에서 하나의 품사 단위로 기능합니다.
목차
  1. 형태소는 무엇인가
  2. 단어는 무엇인가
  3. 어절·단어·형태소 비교
  4. 한 문장을 세 층위로 분석하기
  5. 형태소를 두 기준으로 분류하기
  6. 조사는 왜 단어인가
  7. 형태소 분석과 단어 구조 분석의 차이
  8. 자주 생기는 오해

1. 형태소는 ‘뜻을 가진 가장 작은 말의 단위’다

형태소를 찾을 때 가장 중요한 질문은 더 나누면 원래의 뜻이나 문법 기능이 사라지는가입니다. 한 글자나 한 음절이라는 이유만으로 형태소가 되는 것이 아니라, 그 단위가 일정한 의미를 지녀야 합니다.

책

대상을 가리키는 의미를 지니며 더 작은 의미 단위로 나누기 어렵습니다. 하나의 형태소입니다.

읽었다

읽- / -었- / -다로 나눌 수 있습니다. ‘읽-’은 동작, ‘-었-’은 과거, ‘-다’는 문장을 끝맺는 기능을 나타냅니다.

중요: 형식 형태소도 의미가 없는 것이 아닙니다. 조사와 어미는 대상이나 동작 같은 어휘적 의미보다 관계·시제·종결 같은 문법적 의미와 기능을 나타냅니다.

2. 단어는 ‘혼자 쓰일 수 있느냐’만으로 끝나지 않는다

단어는 보통 분리하여 자립적으로 쓸 수 있는 말이나 이에 준하는 말을 가리킵니다. 학교 문법에서는 여기에 조사도 단어로 포함하는 것이 일반적입니다. 따라서 ‘단어는 무조건 혼자 쓸 수 있는 말’이라고만 외우면 조사를 설명할 수 없습니다.

책, 학교, 매우, 읽었다

문장에서 각각 독립된 단어로 기능합니다. ‘읽었다’는 내부에 여러 형태소가 있지만 활용된 동사 한 단어입니다.

이/가, 을/를

혼자 나타나기 어렵지만 학교 문법에서는 체언과 분리되는 문법적 기능을 지닌 조사이므로 단어로 다룹니다.

주의: 조사·어미의 단어성은 문법 이론에 따라 다르게 설명되기도 합니다. 학교 문법 문제에서는 교과서가 채택한 기준을 우선하되, 현대 학교 문법에서는 조사를 단어로 보는 설명이 일반적입니다.

3. 어절·단어·형태소는 서로 다른 층위다

단위핵심 기준예: ‘철수가’주의할 점
어절띄어쓰기 단위철수가 = 1어절한 어절 안에 둘 이상의 단어가 들어갈 수 있음
단어독립적으로 쓰이는 최소 단위와 이에 준하는 문법 단위철수 / 가 = 2단어조사는 앞말에 붙여 쓰지만 학교 문법에서는 단어로 봄
형태소뜻을 가진 최소 단위철수 / 가 = 2형태소한 단어가 여러 형태소로 이루어질 수 있음

어절은 문장의 겉모양을 띄어쓰기로 나눈 단위이고, 단어는 품사를 부여할 수 있는 중심 단위이며, 형태소는 그 단어 내부를 의미 단위까지 내려가 살피는 단위입니다.

4. ‘철수가 책을 읽었다’를 세 층위로 분석해 보자

철수가 책을 읽었다.

어절: 철수가 / 책을 / 읽었다 → 3어절

단어: 철수 / 가 / 책 / 을 / 읽었다 → 학교 문법 기준 5단어

형태소: 철수 / 가 / 책 / 을 / 읽- / -었- / -다 → 7형태소

이 예에서 가장 중요한 부분은 ‘읽었다’입니다. 단어 분석에서는 활용형 전체가 동사 한 단어이지만, 형태소 분석에서는 어간과 어미를 더 세밀하게 나눕니다.

기본형과 분석형을 섞지 않기: 문장에 ‘읽었다’가 나왔는데 단어 수를 셀 때 임의로 ‘읽다’로 바꾸지 않습니다. ‘읽다’는 사전에서 찾을 때 사용하는 기본형이고, 실제 문장의 단어는 ‘읽었다’입니다.

5. 형태소는 서로 독립적인 두 기준으로 분류한다

형태소는 흔히 자립성과 의미의 성격이라는 두 기준으로 나눕니다. 두 분류는 같은 기준이 아니므로 교차해서 이해해야 합니다.

기준분류뜻예
자립성자립 형태소다른 말에 의존하지 않고 혼자 설 수 있음철수, 책
의존 형태소다른 말에 의존하여 쓰임가, 을, 읽-, -었-, -다
의미 성격실질 형태소구체적인 대상·동작·상태 등을 나타냄철수, 책, 읽-
형식 형태소실질 형태소에 붙어 관계나 문법 기능을 나타냄가, 을, -었-, -다
‘읽-’은 실질 + 의존

동작의 중심 의미가 있으므로 실질 형태소이지만, 어미 없이 문장에서 독립적으로 쓰기 어렵기 때문에 의존 형태소입니다.

‘가’는 형식 + 의존

앞말과 다른 말의 문법적 관계를 표시하고 혼자 쓰이지 않으므로 형식 형태소이면서 의존 형태소입니다.

6. 조사는 의존 형태소인데 왜 단어로 보는가

‘철수가’에서 조사 ‘가’는 혼자 쓸 수 없으므로 의존 형태소입니다. 그런데 학교 문법에서는 ‘철수’와 ‘가’를 각각 단어로 봅니다. 조사와 결합한 앞말을 분리해도 ‘철수’가 그대로 자립성을 유지하고, 조사가 독립된 문법적 기능을 담당하기 때문입니다.

반면 ‘읽었다’의 ‘읽-’과 ‘-었-’, ‘-다’를 분리하면 각 부분을 문장 속 독립 단어로 쓰기 어렵습니다. 그래서 어간과 어미는 형태소로는 나누지만 각각을 별도 단어로 세지 않습니다.

따라서 ‘의존 형태소 = 단어가 아니다’라는 공식도 성립하지 않습니다. 조사는 대표적인 반례입니다. 형태소 분류와 단어 판정은 서로 다른 질문입니다.

7. 형태소 분석과 단어 구조 분석은 목적이 다르다

형태소 분석은 더 이상 나눌 수 없는 의미 단위까지 내려가는 작업입니다. 그러나 단어가 어떻게 만들어졌는지를 볼 때는 처음부터 모든 형태소를 한 줄로 나열하는 것보다 직접 구성 성분을 먼저 찾는 분석이 더 적합할 때가 있습니다.

달맞이의 형태소 분석

달 / 맞- / -이처럼 최소 의미 단위로 나눌 수 있습니다.

달맞이의 직접 구성 성분

먼저 달 + 맞이의 두 덩어리로 나누고, 필요하면 ‘맞이’를 다시 분석합니다.

즉 형태소는 최소 단위를 찾는 개념이고, 직접 구성 성분은 단어가 어떤 단계로 결합해 만들어졌는지를 읽는 분석 방법입니다. 이 구별은 합성어·파생어를 판단할 때 특히 중요합니다.

8. 형태소와 단어에서 자주 생기는 오해

오해바르게 보기
한 글자나 한 음절이면 형태소다.글자 수가 아니라 독립된 의미가 있는 최소 단위인지 판단한다.
형식 형태소는 뜻이 없다.어휘적 의미보다 관계·시제·종결 같은 문법적 의미와 기능을 나타낸다.
의존 형태소는 모두 단어가 아니다.조사는 의존 형태소이지만 학교 문법에서는 일반적으로 단어로 본다.
용언은 어간과 어미를 각각 단어로 센다.형태소 분석에서는 나누지만 ‘읽었다’ 같은 활용형 전체가 한 단어이다.
한자 한 글자는 언제나 한 형태소다.문자 단위와 형태소를 기계적으로 일치시키지 말고 실제 단어의 의미 구조와 사전 분석을 확인한다.
시험에서 분석이 엇갈릴 때: 형태소 경계나 특정 요소의 실질·형식 분류는 문법 이론과 교과서에 따라 설명이 달라지는 사례가 있습니다. 그런 경우에는 문제의 제시문과 교과서 기준을 우선합니다.
