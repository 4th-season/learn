파생어 판별

접사처럼 보이는 조각이 있다고 곧바로 파생어라고 결론 내리면 틀리기 쉽습니다. 먼저 가장 마지막 직접 구성 성분을 찾고, 그 성분이 실제 접사인지 확인한 다음 접사가 더하는 뜻과 결과 단어의 품사를 살펴야 합니다.

파생어 판별의 핵심
① 최종 직접 구성 성분을 찾는다 → ② 한쪽이 실제 접사인지 사전에서 확인한다 → ③ 접사가 새 단어를 만드는 기능인지 본다 → ④ 결과 품사와 의미 변화를 확인한다 → ⑤ 같은 모양의 어미·조사와 구별한다.
목차
  1. 왜 접사부터 찾으면 위험한가
  2. 직접 구성 성분 먼저 찾기
  3. 접사인지 사전에서 확인하기
  4. 품사가 바뀌어야 파생어인가
  5. 접두사와 접미사의 기능
  6. 같은 모양의 어미와 구별하기
  7. 사전 등재를 절대 기준으로 쓰면 안 되는 이유
  8. 문제 풀이 6단계

1. 파생어는 ‘접사가 보이는가’보다 ‘최종 결합에 접사가 있는가’를 본다

파생어와 합성어를 가르는 가장 안전한 출발점은 직접 구성 성분입니다. 국립국어원은 직접 구성 성분 가운데 하나가 접사이면 파생어, 접사가 없으면 합성어로 구분할 수 있다고 설명합니다. 그래서 단어 안에 접사가 어딘가 들어 있다는 사실만으로 최종 단어를 파생어라고 하면 안 됩니다.

지우개

지우- + -개. 최종 직접 구성 성분 가운데 -개가 접사이므로 파생어입니다.

덮밥집

안쪽의 ‘덮밥’에 복잡한 형성 과정이 있더라도 최종 직접 구성 성분이 덮밥 + 집이라면 전체 단어의 최종 유형은 합성어입니다.

분석 순서: 전체 형태소를 한꺼번에 세지 말고, 가장 마지막 결합을 먼저 찾습니다.

2. 사전의 붙임표는 ‘마지막 결합’을 찾는 강한 단서다

표준국어대사전과 우리말샘은 많은 복합어에서 붙임표로 직접 구성 성분을 표시합니다. 예를 들어 지우-개처럼 나타나면 최종 분석 경계가 지우-와 -개 사이에 있다는 뜻입니다. 다만 사전은 합성어·파생어라는 라벨이나 어근/접사 정보를 모두 직접 제공하지 않으므로, 구성 성분을 다시 검색해 성격을 확인해야 합니다.

지우-개 → ‘개’를 사전에서 확인 → 접미사 -개 → 파생어

꽃-집 → ‘꽃’, ‘집’을 확인 → 둘 다 명사 → 합성어

붙임표가 없다고 곧 단일어라는 뜻도 아닙니다. 소리 변화 때문에 구성 경계를 음절 단위로 표시하기 어려운 복합어도 있으므로 사전의 형태·뜻·접사 항목을 함께 봅니다.

단어의 구조 ― 직접 구성 성분부터 이해하기파생어와 합성어 차이

3. ‘접사처럼 느껴진다’가 아니라 실제 접사 항목인지 확인한다

어떤 성분을 접사로 인정하는 데에는 분석 가능성, 비자립성, 생산성, 의미의 독자성 같은 기준이 관여합니다. 따라서 일상적으로 ‘앞에 붙어 뜻을 더하는 것 같다’는 느낌만으로 접두사라고 정하면 위험합니다.

군더더기

사전에 군-더더기로 직접 구성 성분이 표시되고 ‘쓸데없는’의 뜻을 더하는 접두사 군-이 확인됩니다. 따라서 파생어로 볼 수 있습니다.

새싹

‘새로 돋아나는 싹’의 새는 현재 표준국어대사전에서 관형사이고 같은 뜻의 접두사 새-는 실려 있지 않습니다. 따라서 현재 사전 기준에서는 합성어로 분석합니다.

주의: 같은 형태라도 접사인지 어근·단어인지에 대한 분석이 시대나 이론에 따라 달라질 수 있습니다. 학생이라면 교과서·제시문의 분석 체계를 우선합니다.

4. 품사가 바뀌지 않아도 파생어가 될 수 있다

“접미사가 붙어서 품사가 바뀌면 파생어”는 유용한 단서이지만 완전한 정의는 아닙니다. 접사는 새 단어를 만들지만 결과 품사가 반드시 바뀌는 것은 아닙니다.

예접사의 기능품사 변화판단 포인트
지우개-개가 명사를 만듦동사 어근 → 명사품사 변화가 뚜렷한 파생
반짝이다-이다가 동사를 만듦부사/어근 → 동사동사 파생
먹히다피동 접사가 피동 의미를 더함동사 → 동사품사가 유지되어도 파생 가능
세 시간쯤-쯤이 대략의 뜻을 더함앞말 품사 자체를 바꾸지 않음품사 변화만으로 접사를 판정하면 안 됨

따라서 품사 변화는 접사의 기능을 이해하는 보조 정보로 쓰고, 파생어 여부의 첫 기준은 최종 직접 구성 성분에 실제 접사가 들어 있는지를 확인하는 것입니다.

5. 접두사와 접미사는 모두 새 단어를 만들지만 작동 방식은 다양하다

접두사는 어근이나 단어의 앞에, 접미사는 뒤에 붙습니다. 접두사는 흔히 원래 품사를 유지하면서 의미를 제한하거나 강조하는 경우가 많고, 접미사는 새로운 품사를 만들기도 하고 같은 품사 안에서 의미·문법적 성격을 바꾸기도 합니다. 그러나 이를 절대 공식으로 외우기보다 해당 접사 항목의 문법 정보를 확인해야 합니다.

새파랗다

새-는 색채 형용사 앞에 붙어 ‘매우 짙고 선명하게’의 뜻을 더하는 접두사입니다. 결과도 형용사입니다.

지우개·먹보

-개와 -보는 명사를 만드는 접미사로, 결과 품사 확인이 접사의 기능을 이해하는 데 도움이 됩니다.

반짝이다

국립국어원은 부사 ‘반짝’에 동사를 만드는 접미사 -이다가 결합한 것으로 설명합니다.

먹히다

피동 접사가 붙어도 동사라는 품사는 유지될 수 있습니다. ‘품사 변화 없음 = 파생어 아님’은 잘못된 공식입니다.

6. 같은 모양의 어미와 접사는 ‘새 단어인가, 활용인가’로 구별한다

-기, -(으)ㅁ처럼 명사 파생 접미사와 명사형 전성 어미가 같은 형태를 가질 수 있습니다. 이때는 형태가 아니라 기능을 봅니다. 접미사는 새 단어를 만들고, 전성 어미는 용언을 활용하여 문장 안에서 명사와 같은 기능을 하게 할 뿐 원래 품사적 성격을 유지합니다.

줄넘기

사전에 명사로 등재된 하나의 단어입니다. 파생 명사와 관련된 -기로 볼 수 있습니다.

음식물 줄이기

문맥에서 동사 ‘줄이다’의 명사형 활용이므로 -기는 전성 어미로 볼 수 있습니다.

전성 어미와 접사 ― 활용과 파생을 구별하는 법접사의 뜻과 종류 ― 접두사와 접미사

7. 사전에 단어가 없다고 파생어가 아닌 것은 아니다

생산적인 접사가 붙은 모든 파생어가 사전에 개별 표제어로 올라오는 것은 아닙니다. 표준국어대사전 편찬 지침은 생산적인 접사가 결합한 파생어를 선별하여 등재할 수 있다고 설명합니다. 반면 -되다·-하다나 피동 접사가 결합해 널리 쓰이는 파생어는 비교적 폭넓게 표제어로 수록됩니다.

따라서: “사전에 결과 단어가 없다 → 파생어가 아니다”라는 결론은 성립하지 않습니다. 먼저 접사 자체와 결합 조건을 확인하고, 결과 단어가 실제 사용에서 하나의 단어로 기능하는지 문맥과 교과서 분석을 함께 봅니다.

8. 시험과 실제 분석에서 쓰는 6단계 판별 순서

1. 어미를 제외하고 단어 형성의 범위를 잡는다.
용언 활용형의 어미를 파생 접사처럼 세지 않습니다.
2. 가장 마지막 직접 구성 성분을 둘로 나눈다.
사전의 붙임표를 우선적인 단서로 활용합니다.
3. 각 구성 성분을 사전에서 확인한다.
명사·관형사·어근인지, 접두사·접미사인지 실제 품사·문법 정보를 확인합니다.
4. 한 구성 성분이 접사라면 파생어 가능성이 높다.
접사가 새 단어를 만드는 기능으로 쓰였는지 확인합니다.
5. 접사가 더하는 뜻과 결과 품사를 본다.
품사가 바뀌는지 여부는 접사 기능을 이해하는 보조 단서이지 필수 조건은 아닙니다.
6. 동형 어미·조사·경계 사례를 다시 점검한다.
견해가 갈리면 교과서와 문제의 제시 기준을 우선합니다.

핵심만 다시 정리

파생어를 판별할 때 가장 먼저 볼 것은 품사 변화가 아니라 최종 직접 구성 성분에 실제 접사가 포함되는가입니다. 품사 변화는 접사의 기능을 파악하는 중요한 단서지만, 품사가 유지되는 파생도 있습니다. 사전의 붙임표와 접사 항목을 확인하고, 같은 모양의 어미와 구별한 뒤 최종 판정을 내립니다.
형태소와 단어 형성 전체 지도여러 단계의 단어 형성통사적 합성어와 비통사적 합성어
