문법관은 어떻게 읽는가

문법관은 ‘정의 암기 → 문제 풀이’만을 목표로 하지 않습니다. 먼저 개념이 무엇을 구별하기 위해 필요한지 이해하고, 서로 가까운 개념의 경계를 비교한 뒤 실제 문장과 발음 자료에 적용합니다.

개념용어의 뜻과 필요성을 먼저 이해합니다.
관계비슷한 개념이 어디에서 갈라지는지 비교합니다.
적용실제 낱말·문장·담화에서 판단 기준을 사용합니다.

국어 문법의 열 갈래

각 갈래는 앞에서 세운 개념을 다음 갈래가 이어받도록 구성합니다. 현재 연결된 갈래는 바로 열 수 있으며, 나머지 주제도 같은 전체 구조 안에서 읽으면 됩니다.

문법관의 읽기 원칙

대표 개념과 세부 개념을 구분합니다

대표 글에서 전체 구조를 먼저 잡고, 세부 글에서 예외와 판별 기준을 확장합니다.

문자와 소리, 형태와 의미를 섞지 않습니다

같은 낱말도 무엇을 분석하는지에 따라 서로 다른 문법 단위를 사용합니다.

규범과 실제 언어 사용을 구분합니다

표준 규범을 기본으로 익히되 현실 발음과 실제 담화의 변이도 별도 층위에서 이해합니다.

앞 글의 기준을 다음 글에 다시 사용합니다

각 갈래는 독립된 암기 항목이 아니라 하나의 분석 체계로 이어집니다.
