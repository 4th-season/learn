언어의 특성과 기능

언어가 어떤 성질을 지녔는지와 실제 상황에서 무엇을 하는지는 다른 질문입니다. 앞선 특성 글들을 연결하고, 이번에는 발화가 맥락 속에서 어떤 기능을 중심으로 작동하는지 읽습니다.

기존 글은 언어의 여러 특성과 기능을 한 글에 함께 정리했습니다. 닷컴판에서는 기호적 특성과 구조적 특성을 앞선 두 정본으로 분리했으므로, 이 글은 중복을 줄이고 ‘언어는 실제 의사소통에서 무엇을 하는가’에 초점을 둡니다.

소속 안내 · 이 글은 Note 문법관 ‘언어와 국어’ 갈래의 종합·적용 글입니다. 언어의 기호적 특성과 언어의 구조적 특성을 읽은 뒤 보면 역할 차이가 더 분명해집니다.

1. 특성과 기능은 무엇이 다른가

특성은 언어라는 체계가 지닌 성질이고, 기능은 실제 의사소통 상황에서 언어가 수행하는 역할입니다.

언어의 특성

자의성·사회성·역사성, 창조성·체계성·규칙성처럼 언어 체계 자체를 설명합니다.

언어의 기능

정보를 알리고, 감정을 드러내고, 상대의 행동을 이끌고, 관계를 유지하는 등 실제 발화의 역할을 설명합니다.

따라서 “언어는 사회적 약속이다”는 특성에 관한 설명이고, “안녕하세요”가 대화의 접촉을 열고 관계를 유지한다는 것은 기능에 관한 설명입니다.

2. 기능 분류는 하나뿐인가

언어 기능을 나누는 방식은 이론과 교재에 따라 달라질 수 있습니다. 중요한 것은 기능의 이름을 무조건 외우는 것보다 무엇이 중심이 되어 발화가 작동하는지를 읽는 일입니다.

언어학에는 서로 다른 기능 분류가 존재합니다. 예를 들어 어떤 체계는 일곱 기능을 제시하고, 다른 체계는 의사소통의 구성 요소를 기준으로 여섯 기능을 나눕니다. 이 글에서는 한 체계를 일관되게 적용하기 위해 지시적·감정 표현적·행동 촉구적·교감적·시적·메타언어적 기능의 여섯 갈래를 사용합니다.

기존 글에서 바로잡은 점

기존 글은 ‘표현적 기능’과 ‘표출적 기능’을 별도의 항목으로 나누면서 서로 비슷한 감정 표현 역할이 겹쳤습니다. 닷컴판에서는 한 이론의 기준을 일관되게 적용해 중복을 없앴습니다.

3. 여섯 기능 한눈에 보기

기능무엇이 중심인가핵심 질문예
지시적 기능맥락·대상·정보무엇을 알려 주는가?“내일 비가 온대.”
감정 표현적 기능화자화자의 감정·태도가 중심인가?“정말 반갑다!”
행동 촉구적 기능청자상대에게 무엇을 하게 하는가?“문을 닫아 주세요.”
교감적 기능접촉·관계대화를 열고 이어 가는가?“요즘 잘 지내?”
시적 기능메시지의 표현 방식말의 형식 자체가 두드러지는가?운율·반복·말장난·광고 문구
메타언어적 기능언어 코드말 자체의 뜻이나 규칙을 설명하는가?“‘자의성’은 소리와 뜻의 관계가 필연적이지 않다는 뜻이야.”

4. 지시적 기능과 감정 표현적 기능

지시적 기능은 말이 어떤 사실·대상·상황을 가리키고 정보를 전달할 때 두드러집니다. 뉴스, 보고, 설명, 안내에서 흔히 볼 수 있습니다.

“도서관은 오늘 오후 6시에 문을 닫습니다.”
→ 화자의 감정보다 상황에 대한 정보가 중심입니다.

감정 표현적 기능은 화자의 감정과 태도가 중심에 놓입니다. 감탄사뿐 아니라 어조와 표현 선택을 통해서도 나타납니다.

“와, 정말 멋지다.”
→ 대상에 대한 사실보다 화자의 반응이 앞에 드러납니다.

5. 행동 촉구적 기능과 교감적 기능

행동 촉구적 기능은 청자의 행동·생각·반응에 영향을 주려는 기능입니다. 명령·부탁·권유·광고·설득에서 강하게 나타납니다.

“물을 아껴 씁시다.”
→ 정보 전달도 있지만, 중심 목적은 청자의 행동을 이끄는 데 있습니다.

교감적 기능은 새로운 정보를 많이 주지 않더라도 소통의 통로를 열고 관계를 유지하는 데 의미가 있습니다.

“밥 먹었어?”
→ 실제 식사 여부를 묻는 정보 질문일 수도 있지만, 상황에 따라 안부를 묻고 친밀함을 확인하는 표현이 될 수 있습니다.
맥락이 중요한 이유 · 같은 문장도 상황이 바뀌면 중심 기능이 달라질 수 있습니다. 기능 판별은 문장 형태만 보고 결정하지 않고 화자·청자·상황·목적을 함께 봐야 합니다.

6. 시적 기능과 메타언어적 기능

시적 기능은 무엇을 말하는가뿐 아니라 어떻게 말했는가가 중요할 때 두드러집니다. 시의 운율, 반복, 압축된 표현, 광고의 짧고 기억하기 쉬운 문구 등이 대표적입니다.

메타언어적 기능은 언어를 이용해 다시 언어 자체를 설명할 때 나타납니다. 사전 풀이, 문법 수업, 낱말 뜻을 묻고 답하는 상황이 여기에 해당합니다.

“‘주어’가 무슨 뜻이야?” / “문장에서 동작이나 상태의 주체가 되는 성분을 말해.”
→ 소통의 대상이 바깥 세계가 아니라 언어의 표현과 규칙 자체입니다.

7. 한 문장에 기능은 하나뿐인가

실제 발화에서는 여러 기능이 함께 작동하며, 그중 어떤 기능이 지배적인지를 판단하는 편이 정확합니다.

“춥지 않아? 창문 좀 닫아 줄래?”에는 방 안의 상태를 말하는 지시적 기능, 상대에게 행동을 요청하는 행동 촉구적 기능, 공손한 관계를 유지하려는 교감적 요소가 함께 있습니다. 그러나 대화 목적이 창문을 닫게 하는 것이라면 행동 촉구적 기능이 중심이라고 볼 수 있습니다.

읽는 순서
  1. 누가 누구에게 말하는가?
  2. 어떤 상황에서 말하는가?
  3. 이 말로 가장 먼저 이루려는 일이 무엇인가?
  4. 다른 기능이 함께 있더라도 무엇이 중심인가?

8. 문제에서 기능을 판별하는 법

먼저 볼 것판단 기준
화자의 감정감탄·평가·태도가 중심이면 감정 표현적 기능을 우선 검토합니다.
청자의 행동명령·권유·부탁·설득처럼 상대를 움직이려는 목적이면 행동 촉구적 기능을 봅니다.
사실과 상황설명·보고·정보 전달이 중심이면 지시적 기능을 봅니다.
관계 유지인사·안부·말문 열기·대화 이어 가기가 핵심이면 교감적 기능을 봅니다.
표현 형식운율·반복·말장난·표현 효과 자체가 중요하면 시적 기능을 봅니다.
언어 설명낱말의 뜻이나 문법 규칙을 언어로 다시 설명하면 메타언어적 기능을 봅니다.

9. 전체 정리

언어의 특성은 ‘언어는 어떤 체계인가’를, 언어의 기능은 ‘그 체계가 실제 상황에서 무엇을 하는가’를 묻습니다.

자의성·사회성·역사성은 언어 기호의 성격을, 창조성·체계성·규칙성은 언어 구조의 작동 원리를 설명합니다. 이 체계를 실제로 사용하면 정보 전달·감정 표현·행동 촉구·관계 유지·표현 효과·언어 설명과 같은 여러 기능이 나타납니다. 실제 대화에서는 이 기능들이 겹치므로, 문장 하나만 떼어 외우기보다 맥락 속에서 지배적인 기능을 읽는 것이 핵심입니다.
