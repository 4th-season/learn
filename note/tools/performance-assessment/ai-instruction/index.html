주제·관점·현재 작성본은 AI가 대신 정하지 않습니다. 개인정보는 입력하지 마세요.

3. AI 활용 범위를 학생이 선택하세요

교사가 안내한 규정에 맞춰 선택합니다. 사용 금지이거나 규정을 모르면 제출원고 지시문은 만들 수 없습니다.

4. 사용할 첨부자료

파일 자체가 아니라 자료명·출처·핵심 내용과 검증 상태를 입력합니다. 자료가 없으면 AI가 출처를 만들지 않도록 지시합니다.

5. 필요한 AI 지시문을 선택해 출력하세요

세 지시문은 독립적으로 생성됩니다. 필요한 작업만 선택합니다.
